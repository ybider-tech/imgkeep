# Spec: Get colour palette (Imgkeep 0.11.0)

Status: draft for review (Yaron), written 2026-10-20
Why: first step of the "Design Kit" direction. Palette Creator (100K users) has a review asking for colours from images "on sites like Behance"; Imgkeep's Find image here already reaches those images. Competitors in this space are losing trust (popups, paywalls, tracking), so this ships free and keeps every existing promise.

## What the user gets

Right-click an image → **Imgkeep: Save image as → Get colour palette**. A small window shows the image's main colours. Click a colour to copy it, copy them all as code, or save the palette as a file.

Free, forever, like everything Imgkeep has today. No account, no upload: the colours are worked out on the user's computer.

## Scope

In:
1. Menu item **Get colour palette** under the Imgkeep menu, after Copy as PNG and before More options. Contexts: `image`, same as the others. Shows the "New" label for `NEW_DAYS`, like other new items (`MENU_SINCE` / `newItemsSince`).
2. **Find image here** integration: the find window (`find.html`) gets a second button next to Save, "Get colour palette", for the found or picked image.
3. A palette window, `palette.html` + `palette.js`, opened with `openWindow("palette", job)`; size about 440 × 420 in `WINDOWS`.
4. Palette extraction in `lib/palette.js` (new, no dependencies), run in the offscreen document (it has the canvas). Reuses the existing image fetch in `offscreen.js`, including the per-site "Allow and save" flow when a site blocks reads.

Out (later, possibly Pro): CSS/font/style inspection of page elements, boards and collections, sync, history, Figma export, any account.

## The palette window

- Image thumbnail (top), then a row of swatches, largest share first. Each swatch: colour, HEX underneath, share as a percentage on hover.
- Count switch: **5 / 8 / 12** colours (default 5, remembered in local storage as `paletteCount`, like `lastFormat`).
- Format switch: **HEX / RGB / HSL** (remembered as `paletteFormat`).
- Click a swatch → copies that value; a small "Copied" confirmation. Uses `navigator.clipboard.writeText` from the focused window, the same reason Copy as PNG needs no clipboard permission.
- **Copy all as…** menu: CSS variables (`--color-1: #1a2b3c;` …), plain list (one per line), JSON array, Tailwind `colors` snippet.
- **Save palette as…** menu, saved through `chrome.downloads` with the user's folder and file-name template (`{name}` = image name + `-palette`):
  - PNG swatch strip (one block per colour with its HEX printed below, 1200 px wide), drawn on a canvas.
  - `.gpl` (GIMP / Inkscape / Krita palette, plain text).
  - `.ase` (Adobe Swatch Exchange, for Illustrator/Photoshop/InDesign). Small binary writer in `lib/palette.js`, no library.
- Keyboard: Escape closes; arrow keys move between swatches, Enter copies.
- All strings through `_locales` (9 languages), RTL safe (he, ar).

## Extraction (lib/palette.js)

- Input: decoded image on the offscreen canvas (animated images: first frame; SVG: rasterised, as the converter does).
- Downscale so the longer side is at most 200 px before sampling (speed; result barely changes).
- Ignore pixels with alpha < 128.
- Quantise with k-means in Lab colour space (k = requested count, k-means++ seeding, fixed random seed so the same image always gives the same palette), max 20 iterations.
- Merge clusters closer than ΔE 8 (CIE76 is fine) and refill to the requested count from the next-largest clusters.
- Output: `[{ hex, rgb:[r,g,b], share }]`, sorted by share, shares sum to 1.
- Target: under 150 ms for a 4000 × 3000 photo on a mid laptop.
- Pure functions, exported for tests: `extractPalette(imageData, count)`, `toGpl(palette, name)`, `toAse(palette, name)`, `toCssVars(palette)`.

## Permissions, privacy, telemetry

- **No new permissions.** No change to `manifest.json` permissions, `PERMISSIONS.md` table or CSP. `tests/static-check.mjs` must pass unchanged: no new `fetch(`, no new URLs.
- Nothing about the image or its colours leaves the computer.
- Daily summary: add counts `palette_open`, `palette_copy_one`, `palette_copy_all`, `palette_save_png`, `palette_save_gpl`, `palette_save_ase`, `palette_from_find`, and failures under the existing failure keys. Add them to `COUNT_KEYS`, the privacy policy list and the Options "what's sent" view.

## Tests

- Unit (`tests/palette.spec.mjs`): a solid-colour fixture returns that exact colour with share 1; a two-colour 70/30 fixture returns both with shares within ±2%; transparent pixels ignored; same input → same output; `.gpl` and `.ase` round-trip (parse back and compare); CSS vars format.
- Extension (Playwright, `tests/extension.spec.mjs`): menu item exists with the right title and position; clicking it opens the palette window; swatch click puts the HEX on the clipboard; count switch re-renders; Save PNG/GPL/ASE produce files in the test download folder; Find image here → Get colour palette works on the `find` fixture page.
- `npm test` green, static check unchanged.
