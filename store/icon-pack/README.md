# Approved flower icon exports

Cobalt Pop, approved November 2026: photographic orange poppy, white image frame and mint download arrow. The photographic flower is retained at every size.

`imgkeep-icon-variation-{16,32,48,64,128}.png` are canonical extension exports. The 128px export contains artwork within a centred 96px box for Chrome. Website and Edge exports use fuller artwork at their intended display sizes. `python3 scripts/make-icons.py` copies these files without requiring graphics libraries or macOS tools.

Source artwork was generated for Imgkeep and approved in the asset design session. No third-party photography was downloaded. See `store/brand-assets-2026/` for the store-ready upload packs, captions and specifications.
