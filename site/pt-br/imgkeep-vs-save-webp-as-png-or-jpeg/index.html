Imgkeep vs Save webP as PNG or JPEG

Resposta curta

Os dois são gratuitos e de código aberto. O Save webP as PNG or JPEG é um conhecido complemento do Firefox que converte qualquer imagem para PNG ou JPEG com botões sobre a própria imagem. O Imgkeep funciona no Chrome, Edge e Firefox, salva mais formatos, cria GIFs animados no seu computador e não pede acesso a sites logo de início.

Qual escolher?

  • Save webP as PNG or JPEG se você usa Firefox e quer PNG ou JPEG com botões sobre a imagem, além do truque de pedir a imagem de novo para o site mandar JPEG ou PNG.
  • Imgkeep se você também usa Chrome ou Edge, precisa de GIF, PDF ou WebP, quer converter animações no seu computador ou salva fotos de sites que bloqueiam o clique direito.

O que o Save webP as PNG or JPEG faz bem

Um complemento conhecido de jscher2000, de código aberto sob a MPL 2.0 (código no GitHub). A página dele descreve:

  • Qualquer imagem, inclusive WebP e AVIF, para PNG ou JPEG, com qualidade JPEG à escolha.
  • Botões de formato sobre a imagem, e Shift+clique ou Ctrl+clique para salvar PNG ou JPEG na hora.
  • Copiar como PNG, depois que você permite o acesso à área de transferência.
  • Pastas por data ou por site dentro de Downloads.

Perguntas

O Save webP as PNG or JPEG é de código aberto?

Sim. Ele é publicado sob a Mozilla Public License 2.0, com o código no GitHub.

Posso usar os dois?

Sim, no Firefox. Eles adicionam itens separados ao menu do clique direito, então você pode manter os dois e usar o que combinar com a imagem.

Algum dos dois envia minhas imagens?

O Imgkeep converte no seu computador e nunca envia imagens. A página do Save webP as PNG or JPEG não diz onde a conversão acontece, exceto que o botão para WebP animados envia a imagem ao ezgif.com.
