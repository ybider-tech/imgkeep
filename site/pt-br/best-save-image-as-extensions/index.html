Como escolhemos

Em 24 de novembro de 2026 buscamos “save image as”, “save image as type” e “webp to png” na Chrome Web Store, no Edge Add-ons e no Firefox Add-ons, e pegamos as extensões mais visíveis cuja função principal é salvar uma imagem em outro formato, deixando de fora baixadores em massa e busca reversa de imagens. O Imgkeep é nosso. Só listamos o que cada autor informa: um traço não quer dizer que a extensão não faz algo, só que o autor não diz.

Como escolher uma extensão segura

Seja qual for a escolhida, vale gastar alguns minutos verificando: quem salva imagens vê as páginas em que você clica com o botão direito, e uma extensão pode mudar depois de ser vendida.

  1. Permissões. “Ler e alterar todos os seus dados em todos os sites” significa que ela pode ver cada página que você visita. Salvar a imagem em que você clicou com o botão direito não precisa disso.
  2. Dados. Leia a seção Privacidade da página na loja: o que ela diz coletar?
  3. Dono e atualizações. Veja quem publica, e desconfie se uma atualização de repente pedir novas permissões.
  4. Código. Código público permite que outras pessoas confiram o que ela faz.

Qual é a melhor extensão Save Image As?

Depende do que você precisa. Para salvar páginas inteiras de imagens, escolha uma com salvamento em massa. Para salvar a imagem em que você clicou com o botão direito no formato que precisa, sem upload, qualquer uma das extensões de imagem única serve; compare formatos, permissões e se o código é público.
