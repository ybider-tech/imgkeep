    Como obter a paleta de cores de uma imagem sem enviá-la para a internet?

    Solte uma imagem nesta página para ver suas 5, 8 ou 12 cores principais, das mais presentes às menos, com a proporção de cada uma. Clique em uma cor para copiar seu valor HEX, RGB ou HSL, ou copie todas como variáveis CSS ou Tailwind. A imagem é lida no seu navegador e nunca é enviada. Sem cadastro, sem anúncios.

    Atualizado em 28 de outubro de 2026

    Como as cores são escolhidas?

    A imagem é reduzida para 200 pixels no lado mais longo, os pixels transparentes são ignorados e o restante é agrupado por semelhança visual (clusterização k-means no espaço de cor Lab). Cores quase iguais contam como uma só. A mesma imagem sempre gera a mesma paleta.

    Limites

    • Uma imagem por vez.
    • GIF, WebP ou APNG animados: apenas o primeiro quadro.
    • Imagens totalmente transparentes não têm cores a extrair.
    • Fotos HEIC (de iPhones) não podem ser abertas no Chrome, no Edge nem no Firefox.

    Pegue as cores de imagens em páginas da web

    A extensão Imgkeep para Chrome e Edge faz isso com um clique com o botão direito, sem precisar salvar nenhum arquivo antes: clique com o botão direito em qualquer imagem, escolha Imgkeep e depois Obter paleta de cores. Funciona também em fotos que sites como Instagram e Pinterest escondem sob outra camada.

    Perguntas

    Esta ferramenta de paleta de cores é gratuita?

    Sim. Sem conta, sem limite, sem marca d'água e sem anúncios.

    Minha imagem é enviada para algum servidor?

    Não. As cores são calculadas no seu navegador, e a imagem nunca sai do seu dispositivo. A página envia uma contagem anônima da visita e outra se você seguir um link para uma loja — nunca imagens, cores ou nomes de arquivo.

    Por que recebi menos cores do que escolhi?

    A imagem tem menos cores distintas. Cores quase iguais são mescladas, então um logo com três cores chapadas resulta em três, mesmo que você peça 8.

    Quais formatos posso copiar ou salvar?

    Cada cor em HEX, RGB ou HSL. A paleta inteira como variáveis CSS, um trecho de cores para Tailwind, JSON ou uma lista simples. Como arquivo: uma faixa de amostras PNG, uma paleta do GIMP (.gpl, também lida por Inkscape e Krita) ou amostras da Adobe (.ase, para Illustrator, Photoshop e InDesign).

    Dá para obter a paleta de uma imagem em uma página da web?

    Sim, com a extensão gratuita Imgkeep para Chrome e Edge: clique na imagem com o botão direito, escolha Imgkeep e depois Obter paleta de cores. Em sites como Instagram e Pinterest, onde as fotos ficam sob outra camada, escolha Imgkeep: Encontrar imagem aqui…, depois Mais opções e Obter paleta de cores.

    Funciona no meu celular?

    Sim, inclusive em navegadores de celular. A extensão Imgkeep é para Chrome e Edge no desktop.
