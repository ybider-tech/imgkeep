Cada conversão, em uma página própria

O Conversor de imagens gratuito funciona no seu navegador: suas imagens nunca são enviadas. Cada página abaixo abre o conversor já ajustado para uma conversão, com o que ela preserva e o que ela perde.

De HEIC

  • HEIC para JPG: Transforme fotos do iPhone em JPGs que abrem no Windows e em qualquer formulário de upload. A conversão acontece no seu dispositivo: nada é enviado.
  • HEIC para PNG: Tenha um PNG sem perdas de qualquer foto do iPhone, pronto para editar, colar em um design ou inserir em um documento. Ele é criado no seu navegador: nada é enviado.
  • HEIC para PDF: Transforme fotos de documentos, recibos e RGs tiradas no iPhone em PDF, sem fazer upload.

De WebP

  • WebP para JPG: Converta WebP em JPG sem fazer upload: suas imagens ficam no seu dispositivo e não é preciso criar conta.
  • WebP para PNG: Converta WebP em PNG sem fazer upload, com a transparência mantida. Suas imagens ficam no seu dispositivo.
  • WebP para GIF: Transforme WebP animado em um GIF que continua se mexendo, para chats e apps que só tocam GIF.

De AVIF

  • AVIF para JPG: Converta AVIF para JPG sem enviar nada, para apps e formulários que não abrem AVIF.
  • AVIF para PNG: Abra imagens AVIF em qualquer app: converta para PNG com a transparência preservada, sem fazer upload.
  • AVIF para GIF: Transforme AVIF animado em um GIF que toca em qualquer lugar, sem fazer upload.

De JFIF

  • JFIF para JPG: Transforme arquivos .jfif em arquivos .jpg padrão que qualquer app e formulário de upload aceita, sem fazer upload.
  • JFIF para PNG: Transforme imagens .jfif em arquivos PNG para editores e apps que pedem PNG, sem fazer upload.

De PNG

  • PNG para JPG: Converta PNG para JPG sem enviar nada, para arquivos menores. Suas imagens ficam no seu dispositivo.
  • PNG para ICO: Crie um favicon ou ícone do Windows sem enviar nada: um .ico com todos os tamanhos comuns.
  • PNG para WebP: Deixe as imagens PNG do seu site menores, com a transparência preservada, sem fazer upload.
  • PNG para PDF: Transforme capturas de tela, diagramas e gráficos em PDF, com a transparência preservada, sem fazer upload.

De JPG

  • JPG para PNG: Transforme um JPG em PNG para um app ou formulário que pede PNG, sem fazer upload.
  • JPG para PDF: Crie um PDF a partir de uma foto ou digitalização para um formulário ou e-mail, sem fazer upload.
  • JPG para ICO: Crie um favicon ou ícone do Windows a partir de uma foto ou logo em JPG, sem fazer upload.

De SVG

  • SVG para PNG: Transforme um logo ou ícone em SVG em PNG para apps e sites que não abrem SVG, sem fazer upload.
  • SVG para ICO: Crie um favicon ou ícone do Windows nítido a partir do seu logo em SVG, com a transparência preservada, sem fazer upload.
