How we picked them

On 24 November 2026 we searched the Chrome Web Store, Edge Add-ons and Firefox Add-ons for “save image as”, “save image as type” and “webp to png”, and took the most visible extensions whose main job is saving an image in another format, leaving out bulk downloaders and reverse image search. We make Imgkeep. We list only what each publisher states, so a dash doesn't mean an extension can't do something, only that its publisher doesn't say.

How to choose a safe extension

Whichever you pick, a few minutes of checking is worth it: an image saver sees the pages you right-click on, and an extension can change after it's sold.

  1. Permissions. “Read and change all your data on all websites” means it can see every page you visit. Saving the image you right-clicked doesn't need that.
  2. Data. Read the Privacy section of the store listing: what does it say it collects?
  3. Owner and updates. Check who publishes it, and be wary if an update suddenly asks for new permissions.
  4. Source. Public source code lets others check what it does.
