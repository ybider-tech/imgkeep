如何从 X (Twitter) 保存图片

简短回答

在 X 上，每张照片都在指向帖子的链接下面，所以右键给出的是链接选项，而不是“图片另存为”。图片地址还决定了尺寸，例如 name=small 或 name=large。打开图片地址，改成 name=orig 再保存。用 Imgkeep 的话，使用“在此处查找图片”或 Alt+S，并开启“保存完整尺寸版本”获取原图。

更新于 2026 年 11 月 24 日

X 的情况于 2026年11月24日 在 Chrome 中通过 x.com 核对。X 经常变化；如有不同，请发邮件至 helloimgkeep@gmail.com。

为什么不能右键保存 X 上的图片？

X 在帖子里的每张照片上都放了一个链接，所以右键点在链接上，菜单提供的是在新标签页中打开链接等选项，而不是图片另存为。

图片来自 pbs.twimg.com，地址末尾决定尺寸和格式，例如 ?format=jpg&name=small、medium 或 large。name=orig 请求的是上传时的尺寸。

X 上的动图“GIF”其实是短视频，所以图片工具（包括 Imgkeep）无法把它们保存为图片。

不用扩展，如何保存 X 上的图片？

  1. 右键点击照片，选择检查。在高亮的链接旁找到地址以 pbs.twimg.com/media/ 开头的 <img>。
  2. 在新标签页中打开该地址，把 name=small（或 medium、large）改成 name=orig。
  3. 在该标签页中保存图片。如果需要 JPG，把 format=webp 改成 format=jpg。

或者截图，得到屏幕上显示的大小。

如何用 Imgkeep 保存？

Imgkeep 是一款浏览器扩展，可通过右键菜单把图片保存为 PNG、JPG、WebP、GIF 或 PDF。它由我们开发，与 X 没有关联，也未获得 X 的认可。

  1. 右键点击照片，选择 Imgkeep：在此处查找图片…。Imgkeep 会找到链接下的图片并在更多选项中打开，你可以选择 JPG、PNG 或其他格式，然后点保存或复制为 PNG。
  2. 或者把指针放在照片上，按 Alt+S（Mac 上为 Option+S，Firefox 中为 Alt+Shift+S），以你上次使用的格式保存。
  3. 在选项中开启保存完整尺寸版本，Imgkeep 会向 X 的图片服务请求 name=orig，即上传时的尺寸；如果拿不到，就保存你点击的那张图片。

“在此处查找图片”只会找到页面上已经显示的图片。在你开启之前它是关闭的，而且 Imgkeep 只在你要求时才查看页面。

我可以使用保存的图片吗？

保存图片留着以后看、做灵感板或自己参考，和重新使用它是两回事。图片属于创作者，发布在那里的内容受 X 的条款约束。在发布、打印或出售图片之前，请先征得创作者同意并注明出处。只保存你已经能看到的内容；Imgkeep 不会绕过登录、私密账号或付费墙，也不是为此设计的。

常见问题

如何以原始尺寸保存 X 上的图片？

打开图片地址，把 name=small 或 name=large 改成 name=orig。用 Imgkeep 的话，开启“保存完整尺寸版本”，它会替你请求原图。

为什么在 X 上右键显示的是链接选项？

X 在每张照片上都放了一个指向帖子的链接，所以你的右键点在链接上，而不是图片上。

能保存 X 上的 GIF 吗？

不能作为图片保存。X 上的 GIF 是短视频，所以图片保存工具无法把它们保存为 GIF 文件。
