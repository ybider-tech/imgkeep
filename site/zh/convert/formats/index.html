每种转换各有一页

免费图片转换器在你的浏览器中运行：你的图片从不上传。下面每个页面都会打开预设为某一种转换的转换器，并说明这种转换会保留什么、损失什么。

从 HEIC 转换

  • HEIC 转 JPG：把 iPhone 照片转成在 Windows 和任何上传表单里都能打开的 JPG。转换在你的设备上完成，不上传任何内容。
  • HEIC 转 PNG：把任意 iPhone 照片变成无损 PNG，可直接编辑、粘贴到设计稿里或插入文档。PNG 在你的浏览器里生成：不会上传任何内容。
  • HEIC 转 PDF：把 iPhone 拍的文件、收据和证件照片转成 PDF，无需上传。

从 WebP 转换

  • WebP 转 JPG：无需上传即可把 WebP 转成 JPG：图片留在你的设备上，也不用注册账号。
  • WebP 转 PNG：无需上传即可把 WebP 转成 PNG，透明效果照样保留。图片始终留在你的设备上。
  • WebP 转 GIF：把 WebP 动图转成能继续动的 GIF，适合只能播放 GIF 的聊天工具和应用。

从 AVIF 转换

  • AVIF 转 JPG：无需上传即可把 AVIF 转成 JPG，适合打不开 AVIF 的软件和表单。
  • AVIF 转 PNG：让 AVIF 图片在任何应用里都能打开：转成 PNG，保留透明，无需上传。
  • AVIF 转 GIF：把 AVIF 动图转成到处都能播放的 GIF，无需上传。

从 JFIF 转换

  • JFIF 转 JPG：把 .jfif 文件转成任何应用和上传表单都接受的标准 .jpg 文件，无需上传。
  • JFIF 转 PNG：把 .jfif 图片转成编辑器和应用要求的 PNG 文件，无需上传。

从 PNG 转换

  • PNG 转 JPG：无需上传即可把 PNG 转成 JPG，文件更小。图片始终留在你的设备上。
  • PNG 转 ICO：无需上传即可制作 favicon 或 Windows 图标：一个 .ico 文件包含所有常用尺寸。
  • PNG 转 WebP：缩小网站用的 PNG 图片，保留透明，无需上传。
  • PNG 转 PDF：把截图、图表和图形转成 PDF，保留透明，无需上传。

从 JPG 转换

  • JPG 转 PNG：应用或表单要求 PNG？把 JPG 转成 PNG，无需上传。
  • JPG 转 PDF：用照片或扫描件生成 PDF，用于表单或邮件，无需上传。
  • JPG 转 ICO：用照片或标志 JPG 制作网站图标或 Windows 图标，无需上传。

从 SVG 转换

  • SVG 转 PNG：把 SVG 标志或图标转成 PNG，供打不开 SVG 的应用和网站使用，无需上传。
  • SVG 转 ICO：用你的 SVG 标志制作清晰的网站图标或 Windows 图标，保留透明，无需上传。
