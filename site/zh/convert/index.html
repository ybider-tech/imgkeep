    怎样不上传就转换图片？

    用一个在浏览器里完成转换的工具，比如这个。文件由页面在你自己的设备上读取并转换，用的是和 Imgkeep 扩展相同的代码。什么都不会发送到服务器，所以事后没有东西需要删除，也不用注册账号。

    你可以自己验证：打开页面，关掉 Wi-Fi，再转换一个文件，照样能用。或者在转换时看看浏览器的「网络」面板：没有任何请求带着你的图片。

    我该转成哪种格式？

    格式适合透明
    PNG标志、截图、图形，以及之后还要再编辑的图片保留
    JPG照片、更小的文件、上传表单不支持：会填上背景色
    WebP网站（文件小）；Safari 不支持保留
    AVIF网站上体积最小的文件；部分旧应用打不开保留
    GIF动图（在 Chrome 和 Edge 中保留动画）只有全透明或不透明
    PDF文档和票据：每张图片一页保留
    ICOfavicon 和 Windows 图标：16、32、48（以及 256）px保留
    BMP需要位图的老软件不支持：会填上背景色

    结果可以直接粘贴，而不是下载吗？

    可以。每个结果都有复制为 PNG：它会把图片以真正的 PNG 放进剪贴板，保留透明背景，随时可以粘贴到 Canva、Figma、Google Slides 或聊天窗口。参见如何把图片放进 Canva、Figma 或 Google Slides。

    WebP 和 AVIF 是什么？为什么我的应用打不开？

    现在很多网站都用 WebP 或 AVIF 发送图片：文件更小，浏览器显示没问题，但旧应用、上传表单和一些设计工具却不接受。转成 PNG 或 JPG 就能解决。更多内容见Chrome 为什么把图片保存为 WebP和如何把 AVIF 保存为 JPG 或 PNG。

    有哪些限制？

    • 一次最多 20 个文件，每个最大 50 MB。
    • GIF 最宽 800 px，最多 600 帧；在 Chrome 和 Edge 中保留动画。
    • ICO 文件包含 16、32 和 48 px，原图足够大时还会加上 256 px。
    • Safari 无法生成 WebP 文件，因此在 Safari 中不提供 WebP 输出。
    • AVIF 需要一个约 1 MB 的编码器（解压后 3.5 MB），在你第一次选择 AVIF 时加载；一张普通照片不到一秒就能转换完。
    • Chrome、Edge 和 Firefox 打不开 HEIC 照片（iPhone 拍的）。
    • 超大图片在手机上会慢一些。

    网页上的图片有更快的办法吗？

    有：Imgkeep 这个 Chrome 和 Edge 扩展，一次右键就能完成同样的事，甚至不需要先有文件：右键点击任意图片，选择 Imgkeep，再选格式。它还能找到 Instagram、Pinterest 等网站藏在另一层下面的照片。

    常见问题

    这个图片转换器免费吗？

    免费。不需要账号，没有每日次数限制，没有水印，也没有广告。

    我的图片会被上传吗？

    不会。图片在你的浏览器里完成转换，不会离开你的设备。页面只发送匿名计数：一次页面访问、你转换成了哪些格式以及文件数量，还有你点击商店链接时的一次点击。绝不包括图片、文件名或文件大小。

    需要注册吗？

    不需要。没有账号，也没有要注册的东西。打开页面，拖入图片，然后下载或复制结果。

    在手机上能用吗？

    能。转换器在手机浏览器里同样可用。而通过右键菜单转换图片的 Imgkeep 扩展，适用于桌面版 Chrome 和 Edge。

    可以转换 HEIC 照片吗？

    暂时还不行。Chrome、Edge 和 Firefox 无法读取 HEIC 图片，所以浏览器里的转换器也打不开它们。
