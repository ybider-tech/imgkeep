    本地转换的工作方式

    你的图片由本页面在你的设备上转换，用的是和 Imgkeep 扩展相同的代码。不会上传任何内容。本站只统计页面浏览量，以及转换了哪些格式、包含多少个文件（例如“webp → jpg，3 个文件”）；从不发送图片内容、文件名或文件大小。

    • 打开本页面后关掉 Wi-Fi：转换照样可用，除 AVIF 之外的所有格式都是如此——AVIF 的编码器会在你第一次选择它时加载。
    • 打开浏览器的开发者工具，切换到 Network 标签页，然后转换一个文件：没有任何请求携带你的图片。
    • 代码是公开的：GitHub 上的 site/convert，其中还有一个测试，用来检查转换过程不发出任何网络请求、并且可以离线工作。

    直接把 .jfif 改名为 .jpg 不行吗？

    行，只有一两个文件时这是最快的办法，而且没有任何损失：里面的图片本来就是 JPEG。文件很多、看不到文件后缀，或者还想调整尺寸、压缩大小时，这个页面更方便。它会按你选择的质量重新保存一个 JPG。

    为什么我会得到 JFIF 文件？

    在一些 Windows 电脑上，一项注册表设置会让浏览器把下载的 JPEG 命名为 .jfif 后缀。彻底解决的方法见为什么 Chrome 把图片存成 JFIF。

    能不再得到 JFIF 文件吗？

    能。安装 Imgkeep 扩展后，在网页上右键点击图片，选择 Imgkeep › JPG。无论 Windows 怎么设置，它总是保存 .jpg 文件。

    常见问题

    JFIF 和 JPG 是一样的吗？

    是的。JFIF 是存储 JPEG 图片的标准方式之一，所以 .jfif 文件就是换了后缀的 JPEG。

    转换会降低画质吗？

    会稍有降低，因为图片要重新保存为 JPG，除非你修改，否则质量为 92。直接改文件名则没有任何损失。

    能把 JFIF 转成 PNG 吗？

    能：见 JFIF 转 PNG。PNG 文件更大，但保留每个像素。
