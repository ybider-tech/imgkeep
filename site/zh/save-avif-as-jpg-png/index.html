如何将 AVIF 保存为 JPG 或 PNG

简短回答

AVIF 是一种较新的图片格式，体积更小，Chrome 会原样保存，但很多应用还打不开它。想得到 JPG 或 PNG，可以用 Imgkeep 这类转换工具保存（右键菜单 › Imgkeep › JPG），也可以在较新的 Mac 上用 Preview 导出，或在装了微软免费 AV1 Video Extension 的 Paint 中导出。

更新于 2026 年 10 月 28 日

什么是 AVIF？

AVIF 是一种较新的图片格式，基于 AV1 视频编码。它最大的优势是体积：同等画质下，AVIF 通常比 JPG 小得多，往往也比 WebP 更小。Chrome、Edge、Firefox 和 Safari 都能显示它。

Chrome 为什么保存成了 AVIF？

Chrome 向网站请求图片时，会说明自己能显示哪些格式，而当前版本会把 AVIF 排在最前面。许多网站和图片服务据此发送体积最小的文件。这时图片另存为…只会原样保存收到的文件，不做任何转换。Chrome 没有可以改变这一点的设置。WebP 也是同样的情况：Chrome 为什么把图片保存为 WebP。

为什么我的软件打不开 AVIF？

浏览器很快就支持了 AVIF，但不少其他软件还没跟上：较旧的照片应用和编辑器、某些办公软件、上传表单，以及印刷服务。在 Windows 上，照片和 Paint 需要先安装微软免费的 AV1 Video Extension（来自 Microsoft Store）才能打开 AVIF。较新版本的 macOS 可以用 Preview 打开 AVIF，旧版本不行。

怎样一步就把 AVIF 保存为 JPG 或 PNG？

扩展可以在你保存的同时完成转换，这样你完全不用去碰 AVIF 文件。它运行在你的浏览器里，所以要挑一个值得信任的（如何判断图片扩展是否安全）。

我们的扩展

Imgkeep

右键点击图片，选择 Imgkeep，再选 JPG 或 PNG。Imgkeep 会读取这张 AVIF，在你自己的电脑上完成转换，并把一个普通的 .jpg 或 .png 保存到下载文件夹，或你指定的文件夹。保存为 JPG 时，透明区域会变成白色，或你选择的颜色。不会上传任何内容。免费且开源。

把 Imgkeep 添加到 Chrome — 免费 仅四项权限。只有在你要求时才读取页面。

不用扩展怎么转换 AVIF？

对已经存在电脑里的文件，最快的办法是用我们的 AVIF 转 JPG 工具，它在你的浏览器里运行，不会上传。想保留透明，就在那里选 PNG。

Windows：Paint

  1. 如果 Paint 打不开 AVIF 文件，请从 Microsoft Store 安装免费的 AV1 Video Extension。
  2. 右键点击保存下来的 .avif 文件，选择打开方式 › Paint。
  3. 文件 › 另存为，然后选 JPEG 图片 或 PNG 图片。

Mac：Preview

  1. 用 Preview 打开这个 .avif 文件。
  2. 文件 › 导出，把格式设为 JPEG 或 PNG。

如果 Preview 打不开，可能是你的 macOS 版本太旧，不支持 AVIF。请改用其他方法。

任意电脑：复制粘贴

在 Chrome 中右键点击图片，选择复制图片，粘贴到图片编辑器里，再保存为 JPG 或 PNG。即使编辑器打不开 AVIF 文件，这个方法也有效，因为 Chrome 已经把图片解码了。透明可能会丢失。如果菜单里没有复制图片，说明有东西盖在图片上：参见右键无法保存图片时怎么办。

截图

Windows 上按 Win+Shift+S，Mac 上按 Cmd+Shift+4。很快，但你得到的是屏幕显示尺寸的图片，不是原图。

在线转换工具

它们能用，但你的图片会被传到别人的服务器上。公开的图片没问题；私人照片还是要三思。

常见问题

AVIF 文件可以就这样留着吗？

如果你用的每个软件都能打开，那就留着：体积小，效果也好。只在某个软件不接受它，或者你要把图片发给别人时再转换。

转换 AVIF 会损失画质吗？

保存为 PNG 会完整保留像素，但文件会大很多。JPG 会重新压缩一次，有一点损失，不过在高质量设置下通常看不出来。关于 WebP 文件，参见如何把 WebP 保存为 JPG 或 PNG。
