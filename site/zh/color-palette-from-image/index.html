    不上传图片，怎么提取它的配色？

    把图片拖到本页面，就能看到它的 5 种、8 种或 12 种主色，按占比从大到小排列，并显示每种颜色的占比。点击任一颜色即可复制它的 HEX、RGB 或 HSL 值，也可以把全部颜色复制为 CSS 变量或 Tailwind 配置。图片只在你的浏览器中读取，不会上传。无需注册，没有广告。

    更新于 2026 年 10 月 28 日

    它是怎么选出这些颜色的？

    它会先把图片的最长边缩小到 200 像素，忽略透明像素，再按人眼看上去的相近程度把其余像素分组（在 Lab 色彩空间中做 k-means 聚类）。看起来几乎一样的颜色会算作一种。同一张图片始终得到同一组配色。

    限制

    • 一次只能处理一张图片。
    • 动态 GIF、WebP 或 APNG：只取第一帧。
    • 完全透明的图片没有颜色可提取。
    • Chrome、Edge 和 Firefox 打不开 HEIC 照片（iPhone 拍的）。

    提取网页上图片的配色

    适用于 Chrome 和 Edge 的 Imgkeep 扩展右键一下就能完成，不用先把图片存下来：右键点击任意图片，选择 Imgkeep，再选 提取配色。对于 Instagram、Pinterest 这类把照片盖在另一层下面的网站，同样可用。

    常见问题

    这个配色工具免费吗？

    免费。无需账号，没有次数限制，没有水印，也没有广告。

    我的图片会被上传吗？

    不会。颜色在你的浏览器中计算，图片不会离开你的设备。页面只会发送一次匿名的页面访问计数，如果你点击前往应用商店的链接，会再发送一次，绝不会发送图片、颜色或文件名。

    为什么得到的颜色比我选的少？

    因为图片中不同的颜色本来就更少。看起来几乎一样的颜色会被合并，所以一个只有三种纯色的标志，即使你选了 8 种，也只会得到三种。

    可以复制或保存成哪些格式？

    单个颜色可复制为 HEX、RGB 或 HSL。整组配色可复制为 CSS 变量、Tailwind 颜色代码片段、JSON 或纯列表。保存为文件时可选：PNG 色块条、GIMP 调色板（.gpl，Inkscape 和 Krita 也能读取）或 Adobe 色板（.ase，适用于 Illustrator、Photoshop 和 InDesign）。

    能直接提取网页上图片的配色吗？

    可以，使用免费的 Imgkeep 扩展（适用于 Chrome 和 Edge）：右键点击图片，选择 Imgkeep，再选 提取配色。在 Instagram、Pinterest 这类照片被盖在另一层下面的网站上，选择 Imgkeep：在此处查找图片…，再选 更多选项，然后选 提取配色。

    在手机上能用吗？

    可以，在手机浏览器中也能用。Imgkeep 扩展则适用于桌面版 Chrome 和 Edge。
