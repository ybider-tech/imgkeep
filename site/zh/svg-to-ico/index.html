    为什么要从 SVG 开始？

    SVG 在每个尺寸下都会重新绘制，所以每个图标尺寸都来自清晰的图像，而不是缩小的照片。用设计工具做的标志往往本来就是 SVG，背景透明，这正是图标需要的。

    浏览器已经接受 SVG 网站图标，还需要 .ico 吗？

    现代浏览器可以通过 <link rel="icon"> 标签使用 SVG 网站图标，但很多浏览器、书签和工具仍会先去网站根目录找 favicon.ico。很多网站两者都提供。

    我的标志在 16 px 下显得太细

    细线和小字在图标尺寸下会消失。用简化版的标志，比如只保留符号或首字母，并加粗线条，在浏览器标签页里会清楚得多。

    常见问题

    SVG 转 ICO 会保留透明吗？

    会。SVG 中留空的区域在图标的每个尺寸中都保持透明。

    文件里有哪些尺寸？

    16、32 和 48 px；SVG 宽度至少 256 px 或本身没有尺寸时还有 256 px。每个尺寸都以 PNG 格式存在 .ico 里。

    能改成 PNG 网站图标吗？

    能，请看 SVG 转 PNG，再用最大宽度设置尺寸。
