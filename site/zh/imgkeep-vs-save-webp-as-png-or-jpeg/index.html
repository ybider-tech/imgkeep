Imgkeep vs Save webP as PNG or JPEG

简短回答

两者都免费且开源。Save webP as PNG or JPEG 是一款老牌 Firefox 附加组件，可在图片上方直接显示按钮，把任何图片转换为 PNG 或 JPEG。Imgkeep 支持 Chrome、Edge 和 Firefox，可保存更多格式，在你的电脑上生成 GIF 动图，而且一开始不需要任何网站访问权限。

谁该选哪个？

  • Save webP as PNG or JPEG：如果你用 Firefox，想要图片上方直接出现的 PNG 或 JPEG 按钮，还想用它重新请求图片、让网站发送 JPEG 或 PNG 的技巧。
  • Imgkeep：如果你也用 Chrome 或 Edge，需要 GIF、PDF 或 WebP，想在自己的电脑上转换动画，或者要从禁用右键的网站保存照片。

Save webP as PNG or JPEG 的长处

这是 jscher2000 开发的老牌附加组件，以 MPL 2.0 开源（GitHub 上的代码）。它的页面介绍：

  • 把任何图片（包括 WebP 和 AVIF）转换为 PNG 或 JPEG，可选 JPEG 质量。
  • 图片上方的格式按钮，按住 Shift 或 Ctrl 点击可立即保存为 PNG 或 JPEG。
  • 复制为 PNG（需先允许访问剪贴板）。
  • 在“下载”文件夹中按日期或网站分文件夹保存。

常见问题

Save webP as PNG or JPEG 是开源的吗？

是的。它以 Mozilla Public License 2.0 发布，源代码在 GitHub 上。

可以两个都用吗？

可以，在 Firefox 中。它们会在右键菜单中添加各自的菜单项，所以可以都保留，按图片选择合适的那个。

它们会上传我的图片吗？

Imgkeep 在你的电脑上转换，从不上传图片。Save webP as PNG or JPEG 的页面没有说明在哪里转换，只提到它针对 WebP 动图的按钮会把图片发送到 ezgif.com。
