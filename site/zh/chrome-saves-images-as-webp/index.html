Chrome 为什么把图片保存为 WebP（以及怎样得到 JPG 或 PNG）

简短回答

Chrome 保存的正是网站发来的那个文件，而现在很多网站发送 WebP，因为在相同质量下它比 JPG 或 PNG 更小。Chrome 没有设置可以改变这一点。想得到 JPG 或 PNG，就得转换图片：在保存时用扩展转换，或者事后用 Paint（Windows）或 Preview（Mac）转换。

更新于 2026 年 10 月 28 日

Chrome 为什么把图片保存为 WebP？

每次 Chrome 向网站请求图片时，都会告知自己能显示哪些格式。当前版本的 Chrome 会把 AVIF 和 WebP 排在前面。很多网站和图片服务据此为你挑选体积最小的文件，因为在相同质量下 WebP 和 AVIF 通常比 JPG 或 PNG 小得多，页面也就加载得更快。

当你选择图片另存为…时，Chrome 保存的就是它收到的那个文件，不做任何转换。由此带来两点：

  • 图片地址可以以 .jpg 结尾，却仍然返回 WebP。决定格式的是浏览器接受什么，而不是文件名。
  • 同一张图片也可能以 AVIF 的形式返回。参见如何把 AVIF 保存为 JPG 或 PNG。
  • 在 Windows 上，JPG 有时会存成 .jfif。那只是命名问题：Chrome 把图片保存成 JFIF。

Chrome 里有设置能阻止这件事吗？

没有。Chrome 既没有保存图片格式的选项，也没有设置能告诉网站你不想要 WebP。所以下面的办法都是在图片本身上做文章：在保存时转换，或者事后转换。

怎样改成得到 JPG 或 PNG？

已经存成 WebP 了？在浏览器里转换现有文件，无需上传：WebP 转 JPG。

1. 复制后粘贴到图片编辑器

右键单击图片，选择复制图片。在 Windows 上粘贴到 Paint（Ctrl+V），然后用文件 › 另存为。在 Mac 上打开 Preview，选择文件 › 从剪贴板新建，然后文件 › 导出。不用安装任何东西。缺点：每张图片要好几步，而且透明背景可能会丢失。

2. 先保存，再转换

照常保存 WebP，用 Paint（Windows）或 Preview（Mac）打开，再保存或导出为 JPEG 或 PNG。同样不用安装任何东西，但每次都会多出一个文件和几次点击。详细步骤：如何把 WebP 保存为 JPG 或 PNG。

3. 截图

在 Windows 上按 Win+Shift+S，在 Mac 上按 Cmd+Shift+4，然后框选图片。只要看得见就能截。缺点：你得到的是屏幕上的画面，而不是原始文件，所以尺寸往往更小，还可能带上页面的一部分。如果右键菜单里根本没有图片相关选项，参见右键无法保存图片时怎么办。

4. 用一个在保存时就转换的扩展

扩展可以在右键菜单里加上“保存为 PNG 或 JPG”的选项，一步到位地按原尺寸替你转换。缺点：你要信任一段在浏览器里运行的代码，所以要谨慎挑选（见下面的检查清单）。

我们的扩展

Imgkeep

Imgkeep 就是我们为此做的免费 Chrome 扩展。右键单击任意图片，选择 Imgkeep，然后选 PNG、JPG、WebP、GIF、PDF 或原始格式。它在你的电脑上完成转换，保存到下载文件夹、你指定的文件夹，或每次都由你选择的位置。只有当你让它在页面中查找图片时它才会读取该页面，从不修改页面，而且代码开源。

把 Imgkeep 添加到 Chrome — 免费 四项权限。不上传，不需要账号。

怎样判断一个图片扩展是否可靠？

旧文章常推荐“Save image as Type”。该扩展易主后被发现向购物网站插入联盟链接，Google 已于 2026 年 3 月将其从 Chrome Web Store 下架（9to5Google）。如果你还装着它，请卸载。无论安装什么扩展，都要检查：

  • 权限。它是否要求在所有网站上“读取和更改你的所有数据”？保存你右键单击的那张图片并不需要这种权限。
  • 数据。读一读商店页面的“隐私”部分。它说明自己会收集什么吗？
  • 所有者和更新。它还在维护吗？开发者最近是否换过？
  • 源代码。代码是否公开，别人能否核查它到底做了什么？

常见问题

能直接把 .webp 文件改名成 .jpg 吗？

改名只改了名字，没改文件本身，内部仍然是 WebP。有些应用会读取文件内容，照样能打开；但很多不会。还是转换一下吧。

WebP 不好吗？

不是。这是个不错的格式，能让网页加载更快，现在的浏览器和操作系统都能显示它。问题在于一些旧软件、某些上传表单，以及部分印刷或设计工具仍然只认 JPG 或 PNG。

选 JPG 还是 PNG？

PNG 会保留每一个像素和透明区域，但文件更大。JPG 文件更小，用于照片完全够用，但不支持透明。详见 WebP 指南。
