如何从 Facebook 保存照片

简短回答

Facebook 经常用其他图层遮住照片，所以右键点不到图片。单独打开照片：照片查看器的选项菜单可能提供“下载”。你自己的照片，请使用“下载你的信息”。或者对你能看到的照片使用 Imgkeep 的“在此处查找图片”或 Alt+S。

更新于 2026年11月24日。未登录时，Facebook 用登录窗口遮住了页面；它的照片查看器需要账号，所以这里只作一般性描述。如有不同，请发邮件至 helloimgkeep@gmail.com。

为什么不能右键点击 Facebook 照片？

Facebook 在信息流和网格中的许多照片上放了其他元素，所以你的右键点在这些元素上，浏览器显示的菜单没有图片另存为。未登录时，Facebook 还会用登录窗口遮住页面。

下文针对的是你登录后能看到的照片。只分享给他人或私密小组的照片仍然是私密的：这里没有任何绕过它的方法。

不用扩展，如何保存 Facebook 照片？

  1. 照片查看器。点击照片单独打开，然后打开它的选项菜单（⋯）。如果有下载，这是最简单的方法。
  2. 你自己的照片。在账户中心的你的信息和权限下，下载你的信息可以获取你所发内容的副本。
  3. 图片地址。右键点击照片，选择检查，在高亮元素附近找到 <img>，在新标签页中打开它的地址并保存。
  4. 截图。得到屏幕上显示的大小。

如何用 Imgkeep 保存？

Imgkeep 是一款浏览器扩展，可通过右键菜单把图片保存为 PNG、JPG、WebP、GIF 或 PDF。它由我们开发，与 Facebook 没有关联，也未获得 Facebook 的认可。

  1. 右键点击照片，选择 Imgkeep：在此处查找图片…。Imgkeep 会以页面提供的最大尺寸找到图层下的图片，并在更多选项中打开：选择 JPG、PNG 或其他格式，然后点保存或复制为 PNG。
  2. 或者把指针放在照片上，按 Alt+S（Mac 上为 Option+S，Firefox 中为 Alt+Shift+S），以你上次使用的格式保存。
  3. 想要最大的副本，请先在查看器中打开照片：信息流中显示的通常更小。

“在此处查找图片”只会找到页面上已经显示的图片。在你开启之前它是关闭的，而且 Imgkeep 只在你要求时才查看页面。

我可以使用保存的图片吗？

保存图片留着以后看、做灵感板或自己参考，和重新使用它是两回事。图片属于创作者，发布在那里的内容受 Facebook 的条款约束。在发布、打印或出售图片之前，请先征得创作者同意并注明出处。只保存你已经能看到的内容；Imgkeep 不会绕过登录、私密账号或付费墙，也不是为此设计的。

常见问题

如何从 Facebook 下载照片？

单独打开照片，在它的选项菜单中找“下载”。你自己的照片，请在账户中心使用“下载你的信息”。

为什么 Facebook 照片上没有“图片另存为”？

Facebook 经常在照片上放其他元素，所以你的右键点不到图片本身。

能保存私密 Facebook 账号的照片吗？

只能保存你被允许看到的内容，而且保存并不代表你可以分享。重新使用前请先征得发布者同意。
