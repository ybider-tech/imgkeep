将图片保存为 PNG、JPG、WebP、GIF 或 PDF 任意图片。你的格式。

Imgkeep 是一个免费的 Chrome 和 Edge 扩展，可以把网页图片保存为 PNG、JPG、WebP、GIF 或 PDF。右键点击即可在你的设备上转换，并保存到你指定的文件夹。

工作原理

  1. 01

    右键点击图片

    在网上找到一张图片，然后右键点击它。

  2. 02

    选择格式

    选择 PNG、JPG、WebP、GIF（保留动画）、PDF 或原始格式。也可以复制为 PNG，或提取配色。

  3. 03

    保存到你的文件夹

    Imgkeep 在你的电脑上完成转换，每次都保存到你想要的位置。

功能

它能做的一切。

  • 记住你的文件夹

    文件夹只需选一次。此后每张图片都会保存到那里，可以放进你命名的子文件夹，而且不会覆盖任何已有文件。

  • 支持 WebP 和 AVIF

    把网站提供的 WebP 和 AVIF 文件，转成任何应用都能打开的 PNG 或 JPG。动图存为 GIF 后依然会动。

  • 复制为 PNG

    把图片以真正的 PNG 放进剪贴板，保留透明背景，再粘贴到聊天、文档或 Canva、Figma、Google Slides 等设计工具里。具体方法。

  • 配色

    在右键菜单里获取图片的主要颜色。可以把单个颜色复制为 HEX、RGB 或 HSL，把全部颜色复制为 CSS 或 Tailwind，也可以保存给 Adobe 应用或 GIMP 使用。也可以把图片拖到这里。

  • 你的文件名

    用原始名称、网站、日期或尺寸来命名文件，例如 {name}-{w}x{h}。

  • 右键用不了的地方也能用

    在 Instagram、Pinterest 这类网站上，照片被盖在另一层下面。选择 在此处查找图片，Imgkeep 就会找到最大尺寸的那张照片。该功能默认关闭，需要你手动开启。

  • 调整尺寸并预览

    设置最大宽度后，过大的图片会自动缩小。更多选项 会在保存前显示效果和真实文件大小，质量和背景也由你决定。

  • PDF、AVIF、ICO 和 BMP

    把图片保存为单页 PDF，或者在更多选项中保存为 AVIF（通常只有 JPG 的一半大小）、用作快捷方式和网站图标的 ICO，或者 BMP。

  • 你已有的文件

    用免费图片转换器转换电脑或手机上的图片。它在网页里运行，所以不会上传任何内容。

详解

Chrome 为什么保存成 WebP

Chrome 保存的就是网站发来的那个文件，而很多网站发来的是 WebP，因为它更小。没有哪个 Chrome 设置能改变这一点：要么在保存时就转换图片，要么事后用 Paint 或 Preview 转换。

操作指南

把 WebP 存成 JPG 或 PNG

右键点击图片，用在你电脑上运行的转换工具存成 PNG 或 JPG，不会上传任何内容。图形和需要透明的选 PNG，照片选 JPG。

阅读 WebP 指南 →

操作指南

把 AVIF 存成 JPG 或 PNG

AVIF 比 WebP 更小，但许多应用和上传表单仍然打不开。下载时直接存成 JPG 或 PNG，或者用 Preview、Paint（需装微软的免费 AV1 扩展）导出。

阅读 AVIF 指南 →

详解

Chrome 保存成 JFIF

.jfif 文件其实就是普通的 JPEG，只是扩展名不同，由 Windows 注册表的一项设置决定。把它改名为 .jpg、一次性修改该设置，或者直接存成 JPG。

阅读 JFIF 指南 →

操作指南

动态 WebP 转 GIF

JPG 和 PNG 只会保留一帧。把动画存成几乎处处都能播放的 GIF，保留播放节奏和透明效果，一步完成，或者用 GIMP 处理。

阅读 GIF 指南 →

操作指南

把图片存成 PDF

Chrome 的打印成 PDF 会把图片放在纸张大小的页面上。你也可以直接从右键菜单生成一个与图片尺寸完全一致的单页 PDF。

常见问题

直接的回答。

Imgkeep 免费吗？
免费。Imgkeep 现有的所有功能都免费，没有广告，也没有限制。我们计划推出带附加功能的付费版 Imgkeep Pro，现有功能将继续免费。
Imgkeep 会上传我的图片吗？
不会。每张图片都在你的电脑上转换，并直接保存到你的文件夹。Imgkeep 唯一发送的，是每天一次的匿名统计：用了哪些功能、哪些保存失败，你可以在选项中关闭。隐私政策。
可以保存哪些格式？
PNG、JPG、WebP、GIF（保留动画）、PDF 或原始格式。它能转换如今许多网站提供的 WebP 和 AVIF 图片，复制为 PNG 还能把图片放进剪贴板。
能提取图片的配色吗？
可以。右键点击图片，选择 Imgkeep，然后选择提取配色。你会看到它的 5、8 或 12 种主色，按占比从大到小排列。点击某个颜色即可复制为 HEX、RGB 或 HSL，也可以把全部颜色复制为 CSS 变量、Tailwind 或 JSON，还能保存为 PNG、GIMP 调色板或 Adobe 色板。全部在你的电脑上计算。
能保存被网站遮住的图片吗，比如 Instagram 或 Pinterest 上的？
可以。右键点击照片，选择 Imgkeep：在此处查找图片。Imgkeep 会查看该页面一次，找到你点击位置下方那张照片的最大尺寸版本，并打开它供你保存。该功能默认关闭，需要你手动开启，而且它从不改动页面。
能转换我电脑里已有的图片吗？
可以。使用 imgkeep.app/convert/ 上的免费图片转换器：拖入文件，选择 PNG、JPG、WebP、AVIF、GIF、PDF 或 ICO，然后下载，或复制为 PNG。它在你的浏览器里运行，不上传任何内容，也无需注册。手机上同样可用。
支持哪些浏览器？
Google Chrome 116 及更高版本，以及 Microsoft Edge，提供 9 种语言。
能一次保存页面上的所有图片吗？
不能。Imgkeep 只保存你右键点击的那一张图片。要保存整页图片，需要批量下载工具。
