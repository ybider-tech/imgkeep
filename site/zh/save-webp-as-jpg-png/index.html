如何在 Chrome 中把 WebP 保存为 JPG 或 PNG

简短回答

右键点击图片，选择 Imgkeep，再选 PNG 或 JPG。WebP 在你的电脑上完成转换，不会上传任何内容。如果不用扩展，可以先把 WebP 保存下来，再用 Paint（文件 › 另存为）或 Preview（文件 › 导出）重新保存。图形和需要透明背景时选 PNG，照片选 JPG。

更新于 2026 年 10 月 28 日

该选 JPG 还是 PNG？

  • PNG 保留每个像素，也保留透明背景，文件更大。适合标志、截图和图形。
  • JPG 文件更小，到哪都能打开，适合照片。它不支持透明，透明区域会变成纯色，通常是白色。

拿不准？选 PNG，它不会丢失任何内容。

怎样一步把 WebP 保存为 PNG 或 JPG？

扩展可以在你保存图片的同时完成转换，直接从右键菜单操作。它在你的浏览器里运行，所以请选一个你信得过的（如何确认图片扩展是否安全）。下面是我们这款扩展的用法。

我们的扩展

Imgkeep

  1. 从 Chrome Web Store 把 Imgkeep 添加到 Chrome。
  2. 右键点击图片，选择 Imgkeep。
  3. 选择 PNG 或 JPG，文件会保存到你的下载文件夹。

在选项中，你可以改为把图片保存到自己指定的文件夹，或者每次都选择位置。你还能设置 JPG 质量、透明图片存为 JPG 时的背景色（默认白色），以及 {name}-{w}x{h} 这样的文件名。它绝不会覆盖已有文件。转换在你的电脑上完成，不会上传任何内容。免费且开源。

把 Imgkeep 添加到 Chrome — 免费 支持 Chrome 116 及更高版本。

不用扩展怎么转换 WebP？

已经有 WebP 文件了？直接在浏览器里转换，不会上传：WebP 转 JPG 或 WebP 转 PNG。

Windows：Paint

  1. 像平常一样保存图片（右键 › 图片另存为…）。
  2. 右键点击保存好的文件，选择 打开方式 › Paint。
  3. 文件 › 另存为，然后选 JPEG 图片 或 PNG 图片。

如果图片原本是透明背景，记得检查一下结果：Paint 可能不会保留透明度。

Mac：Preview

  1. 保存图片，然后用 Preview 打开（在较旧的 macOS 版本上，Preview 可能打不开 WebP）。
  2. 文件 › 导出，把格式设为 JPEG 或 PNG。

任意电脑：复制粘贴

右键点击图片，选择复制图片，粘贴到图片编辑器里，再保存为 JPG 或 PNG。在 Preview 中使用文件 › 从剪贴板新建。这样完全跳过了 WebP 文件，但透明度可能会丢失。

在线转换工具

它们确实能用，但你得把图片上传到别人的服务器。公开图片没什么问题；涉及隐私的图片就要三思了。

转换后的文件为什么打不开？

把 photo.webp 改名成 photo.jpg 并不能转换格式。文件内部依然是 WebP，很多应用会拒绝打开。反过来也一样：网站可能通过以 .jpg 结尾的地址返回 WebP。这里说明了 Chrome 为什么把图片保存为 WebP。

如果图片根本保存不了，可能是它只存在于页面内部（blob: 地址）。Imgkeep 目前还无法保存这类图片，可以用截图代替。在 Instagram 或 Pinterest 上，照片被盖在另一层下面，可以改用Imgkeep：在此处查找图片（右键无法保存图片时怎么办）。

常见问题

怎样不上传就把 WebP 保存为 PNG？

用一个在你自己电脑上运行的转换工具。像 Imgkeep 这样的扩展会在保存时直接在浏览器里完成转换：右键单击 › Imgkeep › PNG。Paint、Preview 以及复制粘贴也都能离线完成。会把图片上传到服务器的，是那些在线转换网站。

把 WebP 转成 JPG 会损失画质吗？

PNG 会原样保留像素。JPG 会再压缩一次，因此有轻微损失，在较高质量设置下通常看不出来。

动态 WebP 怎么办？

JPG 和 PNG 无法保存动画，所以动态 WebP 转换后只会得到其中一帧的静态图片。要保留动画，请改存为 GIF：在 Imgkeep 中选择 GIF（保留动画）。详细步骤：如何把动态 WebP 保存为 GIF。

能让 Chrome 总是保存为 JPG 吗？

不能。Chrome 没有设置保存图片格式的选项，它保存的就是网站发来的文件。AVIF 也一样：参见如何把 AVIF 保存为 JPG 或 PNG。
