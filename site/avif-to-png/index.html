    How local conversion works

    Your images are converted by this page, on your device, with the same code as the Imgkeep extension. Nothing is uploaded. The site counts page views, and which formats were converted with how many files (for example "webp → jpg, 3 files"); it never sends image contents, file names or file sizes.

    Updated 25 November 2026

    Why do I have AVIF files?

    Many sites now send images as AVIF because the files are very small, and your browser saves exactly what it was sent. See how to save AVIF as JPG or PNG to get the right format straight away.

    AVIF and PNG compared

    Should I pick PNG or JPG?

    PNG for graphics, screenshots and anything with a transparent background: it keeps every pixel. JPG for photos you want to share or upload, since the file is much smaller: use AVIF to JPG.

    Why is the PNG so much bigger than the AVIF?

    AVIF is one of the most efficient image formats; PNG saves every pixel without discarding anything. The picture looks the same, but the PNG can be many times the size. Set a Maximum width in Advanced options if it's too big.

    Questions

    Does converting AVIF to PNG lose quality?

    No. The PNG holds exactly the pixels the AVIF shows. It can't add detail the AVIF's compression removed.

    Does it keep transparency?

    Yes. Transparent areas in the AVIF stay transparent in the PNG.

    What about animated AVIF?

    PNG here keeps only the first frame. Choose GIF to keep the animation; see AVIF to GIF.
