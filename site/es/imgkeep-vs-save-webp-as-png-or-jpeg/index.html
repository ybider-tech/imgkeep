Imgkeep vs Save webP as PNG or JPEG

Respuesta corta

Las dos son gratuitas y de código abierto. Save webP as PNG or JPEG es un conocido complemento de Firefox que convierte cualquier imagen a PNG o JPEG con botones sobre la propia imagen. Imgkeep funciona en Chrome, Edge y Firefox, guarda más formatos, crea GIF animados en tu ordenador y no pide acceso a sitios de entrada.

¿Cuál elegir?

  • Save webP as PNG or JPEG si usas Firefox y quieres PNG o JPEG con botones sobre la imagen, además de su truco de volver a pedir la imagen para que el sitio envíe JPEG o PNG.
  • Imgkeep si también usas Chrome o Edge, necesitas GIF, PDF o WebP, quieres convertir animaciones en tu ordenador o guardas fotos de sitios que bloquean el clic derecho.

Lo que Save webP as PNG or JPEG hace bien

Un complemento conocido de jscher2000, de código abierto con licencia MPL 2.0 (código en GitHub). Su ficha describe:

  • Cualquier imagen, WebP y AVIF incluidas, a PNG o JPEG, con calidad JPEG a elegir.
  • Botones de formato sobre la imagen, y Mayús+clic o Ctrl+clic para guardar PNG o JPEG al momento.
  • Copiar como PNG, una vez que permites el acceso al portapapeles.
  • Carpetas por fecha o por sitio dentro de Descargas.

Save webP as PNG or JPEG (Converter) jscher2000 · Firefox

Open source under MPL 2.0, it converts any image, WebP and AVIF included, to PNG or JPEG, with format and quality buttons over the image you right-clicked.

  • Formats saved: PNG, JPEG (quality choice) (Firefox Add-ons listing)
  • Keeps animation: Not in the add-on: a button sends animated WebP to ezgif.com to make a GIF (Firefox Add-ons listing)
  • Bulk save: Not stated
  • Copy as PNG: Yes (optional clipboard permission) (Firefox Add-ons listing)
  • Colour palette: Not stated
  • Saves where right-click is blocked: Not stated
  • Choose folder / file names: Yes: Date or site subfolders inside Downloads (Firefox Add-ons listing)
  • Converts locally (no uploads): Not stated
  • Open source: Yes, MPL 2.0 (Firefox Add-ons listing, Source code on GitHub)
  • Site access: All sites (Firefox Add-ons listing)
  • Permissions requested: all sites, downloads, menus, storage, webRequest, webRequestBlocking; optional clipboardWrite, notifications (Firefox Add-ons listing)
  • Converts any image, including AVIF, to PNG or JPEG (Firefox Add-ons listing)
  • Shift+click saves PNG, Ctrl+click saves JPEG (Firefox Add-ons listing)
  • Re-requests an image as Internet Explorer 11 to get a JPEG or PNG (Firefox Add-ons listing)
  • Stores: Firefox 1.5.5, updated 30 January 2026

Preguntas

¿Save webP as PNG or JPEG es de código abierto?

Sí. Se publica con la Mozilla Public License 2.0 y su código está en GitHub.

¿Puedo usar las dos?

Sí, en Firefox. Añaden opciones distintas al menú contextual, así que puedes tener ambas y usar la que mejor encaje con cada imagen.

¿Alguna de las dos sube mis imágenes?

Imgkeep convierte en tu ordenador y nunca sube imágenes. La ficha de Save webP as PNG or JPEG no dice dónde se hace la conversión, salvo que su botón para WebP animados envía la imagen a ezgif.com.
