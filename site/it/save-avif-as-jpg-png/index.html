Come salvare un AVIF come JPG o PNG

In breve

AVIF è un formato immagine più recente e più leggero che Chrome salva così com'è, ma molte app non riescono ancora ad aprirlo. Per ottenere un JPG o un PNG, salvalo con un convertitore come Imgkeep (clic destro › Imgkeep › JPG), oppure esportalo da Preview su un Mac recente, o da Paint con l'estensione gratuita AV1 Video Extension di Microsoft.

Aggiornato il 28 ottobre 2026

Che cos'è AVIF?

AVIF è un formato immagine più recente, basato sul codec video AV1. Il suo grande vantaggio è il peso: un AVIF di solito è molto più leggero di un JPG della stessa qualità, e spesso anche di un WebP. Chrome, Edge, Firefox e Safari lo visualizzano tutti.

Perché Chrome ha salvato un AVIF?

Quando Chrome chiede un'immagine a un sito, indica quali formati è in grado di mostrare, e le versioni attuali mettono AVIF al primo posto. Molti siti e servizi di immagini usano questa informazione per inviare il file più leggero. Salva immagine con nome… salva poi esattamente ciò che è arrivato, senza convertirlo. Non c'è nessuna impostazione di Chrome per cambiare questo comportamento. Lo stesso succede con WebP: perché Chrome salva le immagini come WebP.

Perché le mie app non aprono gli AVIF?

I browser hanno adottato AVIF in fretta, molti altri programmi no: app per foto ed editor più datati, alcuni strumenti per ufficio, moduli di caricamento e servizi di stampa. Su Windows, Foto e Paint hanno bisogno dell'estensione gratuita AV1 Video Extension di Microsoft (dal Microsoft Store) per poter aprire un AVIF. Le versioni recenti di macOS aprono gli AVIF in Preview; quelle più vecchie no.

Come salvo un AVIF come JPG o PNG in un solo passaggio?

Un'estensione può convertire l'immagine mentre la salvi, così non devi mai avere a che fare con il file AVIF. Gira nel tuo browser, quindi scegline una di cui ti puoi fidare (come capire se un'estensione per immagini è sicura).

La nostra estensione

Imgkeep

Fai clic destro sull'immagine, scegli Imgkeep, poi JPG o PNG. Imgkeep legge l'AVIF, lo converte sul tuo computer e salva un normale .jpg o .png nei download, o in una cartella scelta da te. Le aree trasparenti diventano bianche in un JPG, o del colore che preferisci. Niente viene caricato online. Gratuito e open source.

Come converto un AVIF senza estensione?

Il modo più rapido per i file che hai già: il nostro convertitore da AVIF a JPG funziona nel browser, senza caricare nulla. Scegli PNG se vuoi conservare la trasparenza.

Windows: Paint

  1. Se Paint non apre i file AVIF, installa l'estensione gratuita AV1 Video Extension dal Microsoft Store.
  2. Fai clic destro sul file .avif salvato e scegli Apri con › Paint.
  3. File › Salva con nome, poi Immagine JPEG o Immagine PNG.

Mac: Anteprima

  1. Apri il file .avif in Preview.
  2. File › Esporta, quindi imposta Formato su JPEG o PNG.

Se Preview non lo apre, la tua versione di macOS potrebbe essere troppo vecchia per AVIF. Usa una delle altre soluzioni.

Su qualsiasi computer: copia e incolla

Fai clic destro sull'immagine in Chrome, scegli Copia immagine, incollala in un editor di immagini e salvala come JPG o PNG. Funziona anche quando l'editor non apre i file AVIF, perché Chrome ha già decodificato l'immagine. La trasparenza potrebbe andare persa. Se Copia immagine non compare nel menu, c'è qualcosa sopra l'immagine: vedi quando il clic destro non salva un'immagine.

Uno screenshot

Win+Shift+S su Windows, Cmd+Shift+4 su Mac. Veloce, ma ottieni l'immagine alle dimensioni a cui è mostrata sullo schermo, non l'originale.

Convertitori online

Funzionano, ma la tua immagine finisce sul server di qualcun altro. Va bene per le foto pubbliche; per quelle private pensaci due volte.

Domande

Conviene tenere i file AVIF così come sono?

Se tutte le app che usi li aprono, sì: sono leggeri e si vedono bene. Converti quando qualcosa li rifiuta, o quando devi inviare l'immagine a qualcun altro.

Convertire un AVIF fa perdere qualità?

Salvare in PNG conserva i pixel esattamente come sono, ma il file diventa molto più pesante. JPG comprime di nuovo, con una piccola perdita di solito invisibile con impostazioni di qualità alte. Per i file WebP, vedi come salvare un WebP come JPG o PNG.
