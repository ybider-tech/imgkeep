Questions

Is Imgkeep free?
Yes. Imgkeep is free and open source (MIT), with no account, no ads and no limits. Every feature available today stays free.
Which browsers does Imgkeep work in?
Google Chrome (on Windows, macOS, Linux and ChromeOS) and Microsoft Edge (on Windows, macOS and Linux). The Firefox version is in review at Mozilla and will be listed here once it's approved.
Is Imgkeep the same in every browser?
Almost. In Firefox, images are saved to your Downloads folder or wherever you choose each time, because Firefox can't write into a folder you pick. And the anonymous daily usage summary is off in Firefox unless you allow it when you install.
Can I use Imgkeep on my phone?
The extension is for desktop browsers. On a phone or tablet, use the Free Image Converter on imgkeep.app: it converts images in the browser, without uploading them.
