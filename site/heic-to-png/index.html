    How local conversion works

    Your images are converted by this page, on your device, with the same code as the Imgkeep extension. Nothing is uploaded. The site counts page views, and which formats were converted with how many files (for example "webp → jpg, 3 files"); it never sends image contents, file names or file sizes.

    • Load this page and add a photo, then turn off your Wi-Fi: converting still works. (In Chrome, Edge and Firefox the HEIC decoder loads with your first photo; Safari doesn't need it.)
    • Open your browser's developer tools, choose the Network tab and convert a file: no request carries your image.
    • The code is public: site/convert on GitHub, with a test that checks converting makes no network request and works offline.

    Updated 24 November 2026

    Why won't my iPhone photos open on Windows?

    iPhones save photos as HEIC (the camera's High Efficiency setting), which takes about half the space of a JPG. Windows needs extra codecs from the Microsoft Store to show HEIC, and many upload forms, web apps and older programs refuse it outright. Converting gives you a file that opens everywhere.

    PNG or JPG for a photo?

    JPG, usually. PNG keeps every pixel, so a photo as PNG is several times bigger than as JPG, and some upload forms limit file size. Pick PNG when you'll edit the photo again or need it lossless; otherwise use HEIC to JPG.

    Are my photos uploaded?

    No. This page opens the HEIC file on your device, with an open-source HEIC decoder (libheif) running in your browser, then converts it with the same code as the Imgkeep extension. Nothing is sent anywhere. The PNG doesn't keep the photo's EXIF details, such as where it was taken, so it's also safer to share.

    What about Live Photos and portrait mode?

    You get the photo itself. A Live Photo's few seconds of video and a portrait photo's depth data stay in the original file. The photo comes out the right way up, as your iPhone shows it.

    Does it work on my iPhone?

    Yes. Open this page in Safari, choose your photos and download the results. Safari opens HEIC itself, so nothing extra loads. In Chrome, Edge and Firefox the page loads a HEIC decoder (about 0.5 MB) the first time you add a photo.

    Questions

    Does HEIC to PNG lose quality?

    No. PNG is lossless, so it keeps everything the photo shows. Colours are converted from the iPhone's wider Display P3 range to standard sRGB, which nearly every screen and app uses.

    Can I make the PNG smaller?

    Yes: set a maximum width in Advanced options before converting, or convert to JPG.

    Can I convert HEIF files too?

    Yes. HEIF is the same format family: .heif files open just like .heic ones.
