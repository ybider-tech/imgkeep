So speichern Sie Bilder von X (Twitter)

Kurze Antwort

Auf X liegt jedes Foto unter einem Link zum Beitrag, daher bietet der Rechtsklick Link-Optionen statt Bild speichern unter. Die Bildadresse legt auch die Größe fest, etwa name=small oder name=large. Öffnen Sie die Bildadresse, ändern Sie sie zu name=orig und speichern Sie. Mit Imgkeep nutzen Sie Bild hier finden oder Alt+S und schalten für das Original Version in voller Größe speichern ein.

Aktualisiert am 24. November 2026

Wie X funktioniert, haben wir am 24. November 2026 auf x.com mit Chrome geprüft. X ändert sich oft; wenn etwas anders aussieht, schreiben Sie uns an helloimgkeep@gmail.com.

Warum kann ich ein Bild von X nicht per Rechtsklick speichern?

X legt über jedes Foto in einem Beitrag einen Link, daher landet der Rechtsklick auf dem Link und das Menü bietet Link in neuem Tab öffnen und Ähnliches, nicht Bild speichern unter.

Die Bilder kommen von pbs.twimg.com, und das Ende der Adresse wählt Größe und Format, zum Beispiel ?format=jpg&name=small, medium oder large. name=orig fordert die hochgeladene Größe an.

Animierte „GIFs“ auf X sind in Wirklichkeit kurze Videos, daher können Bildwerkzeuge, Imgkeep eingeschlossen, sie nicht als Bilder speichern.

Wie speichere ich ein Bild von X ohne Erweiterung?

  1. Rechtsklicken Sie auf das Foto und wählen Sie Untersuchen. Suchen Sie neben dem markierten Link das <img>, dessen Adresse mit pbs.twimg.com/media/ beginnt.
  2. Öffnen Sie diese Adresse in einem neuen Tab und ersetzen Sie name=small (oder medium, large) durch name=orig.
  3. Speichern Sie das Bild aus diesem Tab. Ersetzen Sie format=webp durch format=jpg, wenn Sie ein JPG brauchen.

Oder machen Sie einen Screenshot, in der Größe auf dem Bildschirm.

Wie speichere ich es mit Imgkeep?

Imgkeep ist eine Browsererweiterung, die Bilder über das Rechtsklickmenü als PNG, JPG, WebP, GIF oder PDF speichert. Wir entwickeln sie. Sie ist weder mit X verbunden noch von X empfohlen.

  1. Rechtsklicken Sie auf das Foto und wählen Sie Imgkeep: Bild hier finden…. Imgkeep findet das Bild unter dem Link und öffnet es in Weitere Optionen: JPG, PNG oder ein anderes Format wählen, dann Speichern oder Als PNG kopieren.
  2. Oder zeigen Sie auf das Foto und drücken Sie Alt+S (Wahl+S auf dem Mac, Alt+Umschalt+S in Firefox), um es im zuletzt verwendeten Format zu speichern.
  3. Schalten Sie Version in voller Größe speichern in den Optionen ein, und Imgkeep fragt den Bilddienst von X nach name=orig, der hochgeladenen Größe, und speichert das angeklickte Bild, falls es sie nicht bekommt.

Bild hier finden findet nur ein Bild, das bereits auf der Seite angezeigt wird. Es ist aus, bis Sie es einschalten, und Imgkeep sieht sich die Seite nur an, wenn Sie darum bitten.

Darf ich die gespeicherten Bilder verwenden?

Ein Bild zum späteren Ansehen, für ein Moodboard oder als eigene Referenz zu speichern, ist etwas anderes, als es weiterzuverwenden. Bilder gehören denen, die sie gemacht haben, und für das, was dort veröffentlicht ist, gelten die Bedingungen von X. Bevor Sie ein Bild veröffentlichen, drucken oder verkaufen, fragen Sie die Urheberin oder den Urheber und nennen Sie sie. Speichern Sie nur, was Sie bereits sehen; Imgkeep umgeht keine Anmeldungen, privaten Konten oder Bezahlschranken und ist auch nicht dafür gedacht.

Fragen

Wie speichere ich ein Bild von X in Originalgröße?

Öffnen Sie die Bildadresse und ersetzen Sie name=small oder name=large durch name=orig. Mit Imgkeep schalten Sie Version in voller Größe speichern ein, dann fragt es für Sie nach dem Original.

Warum zeigt der Rechtsklick auf X Link-Optionen?

X legt über jedes Foto einen Link zum Beitrag, daher landet Ihr Rechtsklick auf dem Link, nicht auf dem Bild.

Kann ich ein GIF von X speichern?

Nicht als Bild. GIFs auf X sind kurze Videos, daher können Bildspeicher sie nicht als GIF-Dateien speichern.
