So speichern Sie Bilder von Pinterest

Kurze Antwort

Pinterest legt eine weitere Ebene über seine Bilder, daher bietet ein Rechtsklick auf einen Pin meist kein Bild speichern unter, und das Bild im Raster ist eine verkleinerte Kopie. Öffnen Sie den Pin und nutzen Sie das Pinterest-Menü, falls es einen Download anbietet, oder öffnen Sie die Bildadresse und ersetzen Sie die Größe durch originals. Mit Imgkeep wählen Sie Bild hier finden oder drücken Alt+S über dem Pin.

Aktualisiert am 24. November 2026

Wie Pinterest funktioniert, haben wir am 24. November 2026 auf pinterest.com mit Chrome geprüft. Pinterest ändert sich oft; wenn etwas anders aussieht, schreiben Sie uns an helloimgkeep@gmail.com.

Warum kann ich auf Pinterest nicht auf ein Bild rechtsklicken?

Auf Pinterest landet der Rechtsklick meist auf einer Ebene über dem Bild, nicht auf dem Bild selbst, daher zeigt der Browser das Seitenmenü ohne Bild speichern unter. Das Bild ist darunter noch da.

Das Bild, das Sie sehen, ist außerdem eine verkleinerte Kopie. Die Bildadressen von Pinterest enthalten die Größe, etwa i.pinimg.com/236x/… im Raster oder /736x/ und /1200x/ in größeren Ansichten. Dasselbe Bild liegt meist in Originalgröße unter /originals/.

Ohne Anmeldung öffnet ein Klick auf einen Pin das Registrierungsfenster von Pinterest. Alles Folgende setzt voraus, dass Sie angemeldet sind und den Pin sehen.

Wie speichere ich ein Pinterest-Bild ohne Erweiterung?

  1. Das Pinterest-Menü. Öffnen Sie den Pin und sehen Sie im Menü ⋯ nach. Bietet es Bild herunterladen, ist das der einfachste Weg.
  2. Die Bildadresse. Rechtsklicken Sie auf den Pin, wählen Sie Untersuchen und suchen Sie das <img> neben der markierten Ebene. Öffnen Sie seine Adresse in einem neuen Tab, ersetzen Sie die Größe (236x, 736x…) durch originals und speichern Sie das Bild aus diesem Tab. Lädt originals nicht, nehmen Sie die größte Größe, die lädt.
  3. Ein Screenshot. Win+Umschalt+S unter Windows, Cmd+Umschalt+4 auf dem Mac. Klappt immer, aber nur in der Größe auf dem Bildschirm.

Pinterest-Bilder sind oft WebP oder JPG. Wenn eine App die Datei nicht öffnet, lesen Sie wie Sie WebP als JPG oder PNG speichern.

Wie speichere ich es mit Imgkeep?

Imgkeep ist eine Browsererweiterung, die Bilder über das Rechtsklickmenü als PNG, JPG, WebP, GIF oder PDF speichert. Wir entwickeln sie. Sie ist weder mit Pinterest verbunden noch von Pinterest empfohlen.

  1. Rechtsklicken Sie auf den Pin und wählen Sie Imgkeep: Bild hier finden…. Imgkeep findet das Bild unter der Ebene in der größten Größe, die die Seite bietet, und öffnet es in Weitere Optionen: PNG, JPG oder ein anderes Format wählen, dann Speichern oder Als PNG kopieren.
  2. Oder zeigen Sie auf den Pin und drücken Sie Alt+S (Wahl+S auf dem Mac, Alt+Umschalt+S in Firefox), um ihn sofort im zuletzt verwendeten Format zu speichern.
  3. Für die Originalgröße statt der angezeigten Kopie schalten Sie in den Optionen Version in voller Größe speichern ein. Imgkeep fragt dann den Bilddienst von Pinterest nach der originals-Datei und speichert das angeklickte Bild, falls es sie nicht bekommt.

Bild hier finden findet nur ein Bild, das bereits auf der Seite angezeigt wird. Es ist aus, bis Sie es einschalten, und Imgkeep sieht sich die Seite nur an, wenn Sie darum bitten.

Darf ich die gespeicherten Bilder verwenden?

Ein Bild zum späteren Ansehen, für ein Moodboard oder als eigene Referenz zu speichern, ist etwas anderes, als es weiterzuverwenden. Bilder gehören denen, die sie gemacht haben, und für das, was dort veröffentlicht ist, gelten die Bedingungen von Pinterest. Bevor Sie ein Bild veröffentlichen, drucken oder verkaufen, fragen Sie die Urheberin oder den Urheber und nennen Sie sie. Speichern Sie nur, was Sie bereits sehen; Imgkeep umgeht keine Anmeldungen, privaten Konten oder Bezahlschranken und ist auch nicht dafür gedacht.

Fragen

Wie lade ich ein Pinterest-Bild in voller Größe herunter?

Öffnen Sie die Bildadresse und ersetzen Sie die Größe, etwa 736x, durch originals. Mit Imgkeep schalten Sie Version in voller Größe speichern in den Optionen ein, dann erledigt es das für Sie und nimmt das angeklickte Bild, wenn das Original nicht verfügbar ist.

Warum fehlt auf Pinterest Bild speichern unter?

Ihr Rechtsklick landet auf einer Ebene, die Pinterest über das Bild legt, daher zeigt der Browser das Seitenmenü statt des Bildmenüs. Das Bild ist noch auf der Seite, darunter.

Erfährt die Person hinter dem Pin, dass ich ihr Bild gespeichert habe?

Ein Bild im Browser zu speichern, sendet nichts an Pinterest oder die Urheberin. Es zu verwenden, ist etwas anderes: Fragen Sie vor der Weiterverwendung.
