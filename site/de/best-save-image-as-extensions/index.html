So haben wir ausgewählt

Am 24. November 2026 haben wir im Chrome Web Store, bei Edge Add-ons und Firefox Add-ons nach „save image as“, „save image as type“ und „webp to png“ gesucht und die sichtbarsten Erweiterungen genommen, deren Hauptaufgabe es ist, ein Bild in einem anderen Format zu speichern, ohne Massen-Downloader und umgekehrte Bildersuche. Imgkeep ist unsere. Wir nennen nur, was der jeweilige Anbieter angibt: Ein Strich heißt nicht, dass eine Erweiterung etwas nicht kann, nur dass ihr Anbieter es nicht sagt.

So wählen Sie eine sichere Erweiterung

Egal, welche Sie wählen: Ein paar Minuten Prüfung lohnen sich. Ein Bildspeicher sieht die Seiten, auf denen Sie rechtsklicken, und eine Erweiterung kann sich nach einem Verkauf ändern.

  1. Berechtigungen. „Alle Ihre Daten auf allen Websites lesen und ändern“ bedeutet, dass sie jede Seite sehen kann, die Sie besuchen. Um das Bild zu speichern, auf das Sie rechtsgeklickt haben, ist das nicht nötig.
  2. Daten. Lesen Sie den Abschnitt Datenschutz im Store-Eintrag: Was wird laut Angabe erfasst?
  3. Inhaber und Updates. Prüfen Sie, wer sie veröffentlicht, und seien Sie vorsichtig, wenn ein Update plötzlich neue Berechtigungen verlangt.
  4. Quellcode. Öffentlicher Code erlaubt anderen, zu prüfen, was sie tut.

Die vollständige Checkliste und was mit dem ursprünglichen Save image as Type geschah, finden Sie unter eine sichere Alternative zu Save image as Type.

Fragen

Welche Save-Image-As-Erweiterung ist die beste?

Das hängt davon ab, was Sie brauchen. Um ganze Seiten voller Bilder zu speichern, wählen Sie eine mit Massenspeichern. Um das Bild, auf das Sie rechtsgeklickt haben, im gewünschten Format ohne Upload zu speichern, reicht jede der Erweiterungen für einzelne Bilder; vergleichen Sie Formate, Berechtigungen und ob der Code öffentlich ist.

Sind diese Erweiterungen sicher?

Das beurteilen wir nicht für Sie. Die Tabelle zeigt die Berechtigungen, die jede verlangt, und ob ihr Code öffentlich ist, laut eigenem Store-Eintrag oder Paket. Prüfen Sie auch den Datenschutzabschnitt jedes Eintrags, und lesen Sie wie Sie prüfen, ob eine Bild-Erweiterung sicher ist.

Warum steht in einer Zelle Nicht angegeben?

Wir nennen nur, was jeder Anbieter in seinem Store-Eintrag, auf seiner Website, im Paket oder im Code angibt. Nicht angegeben heißt, dass der Anbieter dazu nichts sagt, nicht dass die Erweiterung es nicht kann.
