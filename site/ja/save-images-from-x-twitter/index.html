X (Twitter) から画像を保存する方法

簡単な答え

X では、どの写真も投稿へのリンクの下にあるので、右クリックでは「名前を付けて画像を保存」ではなくリンクの項目が出ます。画像のアドレスでサイズも決まり、name=small や name=large のようになっています。画像のアドレスを開いて name=orig に変え、保存します。Imgkeep なら「ここで画像を探す」か Alt+S を使い、元の画像を得るには「フルサイズ版を保存する」をオンにします。

更新日: 2026年11月24日

X の動作は 2026年11月24日 に Chrome の x.com で確認しました。X はよく変わります。違いに気づいたら helloimgkeep@gmail.com までお知らせください。

X の画像を右クリックで保存できないのはなぜ？

X は投稿内のどの写真にもリンクを重ねているので、右クリックはリンクに当たり、メニューには名前を付けて画像を保存ではなくリンクを新しいタブで開くなどが出ます。

画像は pbs.twimg.com から配信され、アドレスの末尾でサイズと形式が決まります。たとえば ?format=jpg&name=small、medium、large です。name=orig はアップロード時のサイズを求めます。

X のアニメーション「GIF」は実は短い動画なので、Imgkeep を含む画像ツールでは画像として保存できません。

拡張機能なしで X の画像を保存するには？

  1. 写真を右クリックして検証を選びます。強調表示されたリンクの近くで、アドレスが pbs.twimg.com/media/ で始まる <img> を探します。
  2. そのアドレスを新しいタブで開き、name=small（または medium、large）を name=orig に変えます。
  3. そのタブから画像を保存します。JPG が必要なら format=webp を format=jpg に変えます。

またはスクリーンショットを撮ります。画面に表示されたサイズになります。

Imgkeep で保存するには？

Imgkeep は、右クリックメニューから画像を PNG・JPG・WebP・GIF・PDF で保存するブラウザ拡張機能です。私たちが作っています。X とは提携しておらず、X の承認も受けていません。

  1. 写真を右クリックして Imgkeep: ここで画像を探す… を選びます。Imgkeep はリンクの下の画像を見つけてその他のオプションで開くので、JPG・PNG などの形式を選び、保存かPNGとしてコピーを押します。
  2. または、写真にポインタを合わせて Alt+S（Mac では Option+S、Firefox では Alt+Shift+S） を押すと、前回使った形式で保存できます。
  3. オプションでフルサイズ版を保存するをオンにすると、Imgkeep が X の画像サービスにアップロード時のサイズである name=orig を求め、取得できなければクリックした画像を保存します。

「ここで画像を探す」が見つけるのは、すでにページに表示されている画像だけです。オンにするまではオフで、Imgkeep がページを見るのは頼まれたときだけです。

私たちの拡張機能

Imgkeep

右クリックした画像を PNG・JPG・WebP・GIF（アニメーションを保持）・PDF で保存したり、PNG としてコピーしたりできます。フォルダとファイル名を選べて、サイトが覆っている画像も見つけられます。変換はパソコン上で行われ、アップロードもアカウントも不要です。

ImgkeepをChromeに追加 — 無料 Edge と Firefox にも対応。Alt+S にはバージョン 0.15 以降が必要です。

保存した画像を使ってもいいですか？

あとで見るため、ムードボードや自分の参考資料として画像を保存することと、それを再利用することは別のことです。画像は作った人のもので、そこに投稿されたものには X の規約が適用されます。画像を投稿・印刷・販売する前に、作者に許可を取り、クレジットを記してください。保存するのは、すでに見えているものだけにしましょう。Imgkeep はログインや非公開アカウント、有料の壁を回避しませんし、そのためのものでもありません。

よくある質問

X の画像を元のサイズで保存するには？

画像のアドレスを開き、name=small や name=large を name=orig に変えます。Imgkeep なら「フルサイズ版を保存する」をオンにすれば、元の画像を代わりに求めてくれます。

X で右クリックするとリンクの項目が出るのはなぜ？

X はどの写真にも投稿へのリンクを重ねているので、右クリックは画像ではなくリンクに当たります。

X の GIF を保存できますか？

画像としてはできません。X の GIF は短い動画なので、画像保存ツールでは GIF ファイルとして保存できません。
