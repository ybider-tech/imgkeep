安全な拡張機能の選び方

どれを選ぶにしても、数分かけて確認する価値があります。画像保存ツールは右クリックしたページを見ることができ、拡張機能は売却後に変わることがあるからです。

  1. 権限。「すべてのウェブサイト上にあるユーザーのデータの読み取りと変更」は、閲覧するすべてのページを見られることを意味します。右クリックした画像を保存するだけなら必要ありません。
  2. データ。ストアページのプライバシー欄を読み、何を収集すると書いてあるか確認しましょう。
  3. 所有者と更新。誰が公開しているかを確認し、更新で急に新しい権限を求められたら注意しましょう。
  4. ソースコード。コードが公開されていれば、何をしているか他の人が確かめられます。

よくある質問

一番いい Save Image As 拡張機能は？

目的によります。ページの画像をまとめて保存したいなら、一括保存できるものを選んでください。右クリックした画像を必要な形式でアップロードなしに保存したいなら、ここにある 1 枚ずつ保存する拡張機能のどれでも使えます。形式、権限、コードが公開されているかを比べてください。

これらの拡張機能は安全ですか？

私たちが代わりに判断することはしません。表には、各拡張機能自身のストアページやパッケージに基づいて、求める権限とコードが公開されているかを載せています。各ストアページのプライバシー欄も確認し、画像の拡張機能が安全か確かめる方法もご覧ください。

「明記なし」と書かれた欄があるのはなぜ？

各公開元がストアページ、ウェブサイト、パッケージ、コードで述べていることだけを載せています。「明記なし」は公開元がそれについて何も書いていないという意味で、拡張機能にできないという意味ではありません。
