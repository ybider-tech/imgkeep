ChromeがWebPで画像を保存する理由（とJPG・PNGで保存する方法）

簡単な答え

Chromeはウェブサイトが送ってきたファイルをそのまま保存します。そして今は多くのサイトがWebPを送ります。同じ品質ならJPGやPNGよりファイルが小さいからです。これを変える設定はChromeにありません。JPGやPNGで手に入れるには、画像を変換します。保存するときに拡張機能で変換するか、保存したあとにPaint（Windows）やPreview（Mac）で変換します。

更新日: 2026年10月28日

ChromeはなぜWebPで画像を保存するの？

Chromeはサイトに画像をリクエストするたびに、自分が表示できる形式も伝えています。現在のChromeはAVIFとWebPを最初に挙げます。多くのサイトや画像配信サービスはそれを見て、いちばん小さいファイルを選びます。同じ品質なら、WebPやAVIFは通常JPGやPNGよりずっと小さいからです。その分ページの表示も速くなります。

名前を付けて画像を保存…を選ぶと、Chromeは受け取ったファイルをそのまま保存します。変換は一切しません。そこから2つのことが言えます。

  • 画像のアドレスが .jpg で終わっていても、中身はWebPということがあります。形式を決めるのは名前ではなく、ブラウザが受け入れられる形式です。
  • 同じ画像がAVIFで届くこともあります。AVIFをJPGやPNGで保存する方法をご覧ください。
  • Windowsでは、JPGが .jfif として保存されることがあります。これは名前だけの問題です：ChromeがJFIFで画像を保存する。

これをやめさせるChromeの設定はある？

ありません。Chromeには保存する画像の形式を決めるオプションも、WebPは要らないとサイトに伝える設定もありません。そのため、以下の方法はどれも画像そのものに働きかけます。保存するときに変換するか、保存したあとに変換するかです。

代わりにJPGやPNGで保存するには？

すでにWebPを保存してしまった場合は、手元のファイルをアップロードせずにブラウザ内で変換できます：WebPをJPGに変換。

1. 画像編集ソフトにコピー＆ペーストする

画像を右クリックして画像をコピーを選びます。Windowsでは Paint に貼り付け（Ctrl+V）、ファイル › 名前を付けて保存を使います。Macでは Preview を開き、ファイル › クリップボードから新規作成、続いてファイル › 書き出すを選びます。インストールは不要です。難点は、画像1枚ごとに何手順もかかることと、透過した背景が失われる場合があることです。

2. 保存してから変換する

WebPをいつも通り保存し、Paint（Windows）やPreview（Mac）で開いて、JPEGまたはPNGとして保存・書き出します。これもインストールは不要ですが、ファイルが2つできてしまい、毎回ひと手間増えます。手順はこちら：WebPをJPGやPNGで保存する方法。

3. スクリーンショットを撮る

WindowsではWin+Shift+S、MacではCmd+Shift+4を押して、画像の範囲を選びます。目に見えるものなら何でも撮れます。難点は、得られるのは元のファイルではなく画面に映っているものなので、サイズが小さくなりがちで、ページの一部が写り込むこともある点です。右クリックメニューにそもそも画像の項目が出ない場合は、右クリックで画像を保存できないときをご覧ください。

4. 保存と同時に変換する拡張機能を使う

拡張機能なら、右クリックメニューに「PNGやJPGで保存」という項目を追加して、元のサイズのまま一度の操作で変換できます。難点は、ブラウザ内で動くコードを信頼することになる点です。選ぶときは慎重に（下のチェックリストを参照）。

私たちの拡張機能

Imgkeep

私たちは、まさにこのための無料のChrome拡張機能 Imgkeep を作っています。画像を右クリックしてImgkeepを選び、PNG、JPG、WebP、GIF、PDF、元の形式から選ぶだけです。変換は自分のパソコン上で行い、ダウンロードフォルダ、指定したフォルダ、または毎回選ぶ場所に保存します。ページを見るのは、そのページで画像を探すよう指示したときだけで、ページを書き換えることは決してありません。ソースコードも公開しています。

ImgkeepをChromeに追加 — 無料 権限は4つだけ。アップロードもアカウントも不要です。

画像の拡張機能はどう見極める？

古い記事では「Save image as Type」がよくすすめられています。この拡張機能は所有者が変わったあと、ショッピングサイトにアフィリエイトリンクを差し込んでいることが判明し、Googleが2026年3月にChrome Web Storeから削除しました（9to5Google）。まだ入れている場合は削除してください。どの拡張機能を入れるにしても、次の点を確認しましょう。

  • 権限。すべてのウェブサイトで「すべてのデータの読み取りと変更」を求めていませんか。右クリックした画像を保存するだけなら、その権限は必要ありません。
  • データ。ストアの掲載ページの「プライバシー」の項目を読みましょう。何かを収集すると書かれていませんか。
  • 所有者と更新。今もメンテナンスされていますか。開発者が最近変わっていませんか。
  • ソースコード。コードは公開されていて、第三者が動作を確認できますか。

よくある質問

.webpファイルの名前を.jpgに変えるだけではだめ？

名前を変えても変わるのは名前だけで、ファイルの中身はWebPのままです。中身を見て開いてくれるアプリもありますが、開けないものも多くあります。名前を変えるのではなく変換してください。

WebPは良くない形式なの？

いいえ。ページの読み込みを速くしてくれる優れた形式で、最近のブラウザやOSなら表示できます。問題になるのは、いまだにJPGやPNGを前提にしている古いアプリ、一部のアップロードフォーム、一部の印刷・デザインツールです。

JPGとPNG、どちらがいい？

PNGはすべてのピクセルと透過をそのまま残しますが、ファイルは大きくなります。JPGはファイルが小さく写真に向いていますが、透過には対応していません。詳しくはWebPのガイドをご覧ください。
