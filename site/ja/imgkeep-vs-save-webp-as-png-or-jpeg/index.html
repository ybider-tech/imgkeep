Imgkeep vs Save webP as PNG or JPEG

簡単な答え

どちらも無料でオープンソースです。Save webP as PNG or JPEG は、画像の上に直接ボタンを出して、どんな画像も PNG か JPEG に変換する定番の Firefox アドオンです。Imgkeep は Chrome・Edge・Firefox で使え、保存できる形式が多く、アニメーション GIF をパソコン上で作り、最初からサイトへのアクセスを求めません。

どちらを選ぶ？

  • Save webP as PNG or JPEG：Firefox を使っていて、画像の上に出るボタンで PNG や JPEG を保存したい人。サイトに JPEG や PNG を送らせるために画像を再リクエストする機能も便利です。
  • Imgkeep：Chrome や Edge も使う人、GIF・PDF・WebP が必要な人、アニメーションを自分のパソコンで変換したい人、右クリックを禁止しているサイトの写真を保存したい人。

Save webP as PNG or JPEG の得意なこと

jscher2000 による定番アドオンで、MPL 2.0 のオープンソースです（GitHub のコード）。ストアページには次のように書かれています。

  • WebP や AVIF も含むあらゆる画像を PNG か JPEG に変換。JPEG の画質も選べます。
  • 画像の上に形式ボタン。Shift＋クリックか Ctrl＋クリックで PNG か JPEG をすぐ保存。
  • クリップボードへのアクセスを許可すると、PNG としてコピーできます。
  • ダウンロードフォルダ内に日付別・サイト別のフォルダを作れます。

よくある質問

Save webP as PNG or JPEG はオープンソースですか？

はい。Mozilla Public License 2.0 で公開されていて、ソースコードは GitHub にあります。

両方使えますか？

はい、Firefox なら使えます。右クリックメニューにそれぞれ別の項目が追加されるので、両方入れておいて画像に合うほうを使えます。

どちらかが画像をアップロードしますか？

Imgkeep はパソコン上で変換し、画像をアップロードすることはありません。Save webP as PNG or JPEG のストアページには変換の場所が書かれていませんが、アニメーション WebP 用のボタンは画像を ezgif.com に送ると書かれています。
