Facebook の写真を保存する方法

簡単な答え

Facebook は写真をほかのレイヤーで覆っていることが多く、右クリックが画像に届きません。写真を単独で開くと、写真ビューアのオプションメニューに「ダウンロード」があるかもしれません。自分の写真は「個人の情報をダウンロード」を使います。または、見えている写真に Imgkeep の「ここで画像を探す」か Alt+S を使います。

2026年11月24日 更新。ログインしていない状態では、Facebook はページをログイン画面で覆っていました。写真ビューアにはアカウントが必要なため、ここでは一般的な説明にとどめています。違いに気づいたら helloimgkeep@gmail.com までお知らせください。

Facebook の写真を右クリックできないのはなぜ？

Facebook はフィードやグリッドの多くの写真にほかの要素を重ねているので、右クリックはそれに当たり、ブラウザは名前を付けて画像を保存のないメニューを表示します。ログインしていないと、Facebook はページをログイン画面でも覆います。

以下はログインして見えている写真についての説明です。特定の人だけに共有された写真や、非公開グループの写真は非公開のままです。ここにそれを回避する方法はありません。

拡張機能なしで Facebook の写真を保存するには？

  1. 写真ビューア。写真をクリックして単独で開き、オプションメニュー（⋯）を開きます。ダウンロードがあれば、それがいちばん簡単です。
  2. 自分の写真。アカウントセンターの個人の情報とアクセス許可で、個人の情報をダウンロードを使うと投稿したもののコピーが手に入ります。
  3. 画像のアドレス。写真を右クリックして検証を選び、強調表示された要素の近くの <img> を探し、そのアドレスを新しいタブで開いて保存します。
  4. スクリーンショット。画面に表示されたサイズになります。

Imgkeep で保存するには？

Imgkeep は、右クリックメニューから画像を PNG・JPG・WebP・GIF・PDF で保存するブラウザ拡張機能です。私たちが作っています。Facebook とは提携しておらず、Facebook の承認も受けていません。

  1. 写真を右クリックして Imgkeep: ここで画像を探す… を選びます。Imgkeep はレイヤーの下の画像を、ページが提供するいちばん大きなサイズで見つけてその他のオプションで開きます。JPG・PNG などの形式を選び、保存かPNGとしてコピーを押します。
  2. または、写真にポインタを合わせて Alt+S（Mac では Option+S、Firefox では Alt+Shift+S） を押すと、前回使った形式で保存できます。
  3. いちばん大きなコピーがほしいときは、まず写真ビューアで写真を開いてください。フィードでは小さいものが表示されることがよくあります。

「ここで画像を探す」が見つけるのは、すでにページに表示されている画像だけです。オンにするまではオフで、Imgkeep がページを見るのは頼まれたときだけです。

私たちの拡張機能

Imgkeep

右クリックした画像を PNG・JPG・WebP・GIF（アニメーションを保持）・PDF で保存したり、PNG としてコピーしたりできます。フォルダとファイル名を選べて、サイトが覆っている画像も見つけられます。変換はパソコン上で行われ、アップロードもアカウントも不要です。

ImgkeepをChromeに追加 — 無料 Edge と Firefox にも対応。Alt+S にはバージョン 0.15 以降が必要です。

保存した画像を使ってもいいですか？

あとで見るため、ムードボードや自分の参考資料として画像を保存することと、それを再利用することは別のことです。画像は作った人のもので、そこに投稿されたものには Facebook の規約が適用されます。画像を投稿・印刷・販売する前に、作者に許可を取り、クレジットを記してください。保存するのは、すでに見えているものだけにしましょう。Imgkeep はログインや非公開アカウント、有料の壁を回避しませんし、そのためのものでもありません。

よくある質問

Facebook の写真をダウンロードするには？

写真を単独で開き、オプションメニューで「ダウンロード」を探します。自分の写真は、アカウントセンターの「個人の情報をダウンロード」を使います。

Facebook の写真に「名前を付けて画像を保存」がないのはなぜ？

Facebook は写真の上にほかの要素を重ねていることが多く、右クリックが画像そのものに当たらないためです。

非公開の Facebook アカウントの写真を保存できますか？

見ることを許されたものだけです。保存しても共有してよいことにはなりません。再利用する前に投稿した人の許可を取りましょう。
