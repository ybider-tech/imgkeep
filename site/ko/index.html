이미지를 PNG, JPG, WebP, GIF, PDF로 저장 모든 이미지를. 원하는 형식으로.

Imgkeep은 웹 이미지를 PNG, JPG, WebP, GIF, PDF로 저장하는 무료 Chrome·Edge 확장 프로그램입니다. 우클릭하면 내 기기에서 변환해 내가 고른 폴더에 저장합니다.

사용 방법

  1. 01

    이미지를 우클릭하세요

    웹에서 이미지를 찾아 우클릭하세요.

  2. 02

    형식을 고르세요

    PNG, JPG, WebP, GIF (애니메이션 유지), PDF, 원본 형식 중에서 고르세요. PNG로 복사하거나 색상 팔레트를 볼 수도 있습니다.

  3. 03

    원하는 폴더에 저장

    Imgkeep이 내 컴퓨터에서 변환해 매번 원하는 위치에 저장합니다.

설치도, 업로드도 필요 없습니다

이미 가지고 있는 이미지를 변환하세요.

WebP, AVIF, PNG, JPG 파일을 끌어다 놓으면 브라우저 안에서 바로 PNG, JPG, AVIF, GIF, PDF, ICO로 바꿔 줍니다. 업로드도, 가입도 없습니다.

기능

Imgkeep이 하는 일 전부.

  • 폴더를 기억합니다

    폴더를 한 번만 정해 두면 모든 이미지가 그곳에, 직접 이름 붙인 하위 폴더에 저장됩니다. 기존 파일을 덮어쓰는 일도 없습니다.

  • WebP와 AVIF도 문제없이

    사이트가 내려주는 WebP·AVIF 파일을 어떤 앱에서나 열리는 PNG나 JPG로 바꿉니다. 움직이는 이미지는 GIF로 저장해 그대로 움직입니다.

  • PNG로 복사

    투명도를 유지한 진짜 PNG로 클립보드에 담아 채팅, 문서, 또는 Canva, Figma, Google Slides 같은 디자인 도구에 붙여넣으세요. 방법 보기.

  • 색상 팔레트

    우클릭 메뉴에서 이미지의 주요 색상을 확인하세요. 색 하나를 HEX, RGB, HSL로 복사하거나, 전체를 CSS나 Tailwind로 복사하거나, Adobe 앱과 GIMP용으로 저장할 수 있습니다. 여기에 이미지를 끌어다 놓아도 됩니다.

  • 내가 정하는 파일 이름

    원본 이름, 사이트, 날짜, 크기로 파일 이름을 만드세요. 예를 들면 {name}-{w}x{h}처럼요.

  • 우클릭이 안 되는 곳에서도

    Instagram이나 Pinterest 같은 사이트에서는 사진이 다른 레이어 아래에 숨어 있습니다. 여기서 이미지 찾기를 선택하면 Imgkeep이 가장 큰 크기의 사진을 찾아냅니다. 직접 켜기 전까지는 꺼져 있습니다.

  • 크기 조절과 미리보기

    최대 너비를 정해 두면 큰 이미지가 거기에 맞춰 줄어듭니다. 추가 옵션에서는 저장하기 전에 결과물과 실제 파일 크기를 보여주고, 품질과 배경도 직접 고를 수 있습니다.

  • PDF, AVIF, ICO, BMP

    이미지를 한 장짜리 PDF로 저장하거나, 추가 옵션에서 AVIF(보통 JPG의 절반 크기), 바로 가기와 파비콘에 쓰는 ICO 아이콘, BMP로 저장하세요.

  • 이미 가지고 있는 파일

    컴퓨터나 휴대폰에 있는 이미지는 무료 이미지 변환기로 변환하세요. 페이지 안에서 실행되므로 아무것도 업로드되지 않습니다.

설명

Chrome이 WebP로 저장하는 이유

Chrome은 사이트가 보낸 파일을 그대로 저장하는데, 많은 사이트가 용량이 작다는 이유로 WebP를 보냅니다. 이를 바꾸는 Chrome 설정은 없습니다. 저장할 때 바로 변환하거나, 저장한 뒤 Paint나 Preview에서 변환하세요.

질문

군더더기 없는 답변.

Imgkeep은 무료인가요?
네. 지금 Imgkeep이 제공하는 모든 기능은 무료이며, 광고도 제한도 없습니다. 추가 기능을 담은 유료 Imgkeep Pro를 준비 중이지만, 지금의 기능은 계속 무료입니다.
Imgkeep이 제 이미지를 업로드하나요?
아니요. 모든 이미지는 내 컴퓨터에서 변환되어 지정한 폴더에 바로 저장됩니다. Imgkeep이 보내는 것은 어떤 기능을 썼고 어떤 저장이 실패했는지에 대한 하루 한 번의 익명 집계뿐이며, 옵션에서 끌 수 있습니다. 개인정보처리방침.
어떤 형식으로 저장할 수 있나요?
PNG, JPG, WebP, GIF(애니메이션 유지), PDF 또는 원본 형식입니다. 요즘 많은 사이트가 제공하는 WebP와 AVIF 이미지도 변환하며, PNG로 복사를 쓰면 이미지가 클립보드에 담깁니다.
이미지에서 색상 팔레트를 뽑을 수 있나요?
네. 이미지를 오른쪽 버튼으로 클릭하고 Imgkeep, 색상 팔레트 보기를 차례로 고르세요. 주요 색상 5개, 8개, 12개를 비중이 큰 순서대로 보여줍니다. 색을 클릭하면 HEX, RGB, HSL로 복사할 수 있고, 전체를 CSS 변수, Tailwind, JSON으로도 복사할 수 있습니다. PNG 색상표, GIMP 팔레트, Adobe 스와치로 저장할 수도 있습니다. 모든 계산은 내 컴퓨터에서 이루어집니다.
Instagram이나 Pinterest처럼 사이트가 가려 놓은 이미지도 저장할 수 있나요?
네. 사진을 오른쪽 버튼으로 클릭하고 Imgkeep: 여기서 이미지 찾기를 고르세요. Imgkeep이 그 페이지를 한 번 살펴보고 클릭한 자리 아래에 있는 사진을 가장 큰 크기로 찾아 바로 저장할 수 있게 엽니다. 직접 켜기 전에는 꺼져 있으며, 페이지를 바꾸지 않습니다.
이미 컴퓨터에 있는 이미지도 변환할 수 있나요?
네. imgkeep.app/convert/에 있는 무료 이미지 변환기를 쓰세요. 파일을 끌어다 놓고 PNG, JPG, WebP, AVIF, GIF, PDF, ICO 중에서 고른 뒤 내려받거나 PNG로 복사하면 됩니다. 브라우저에서 실행되므로 업로드도 가입도 없습니다. 휴대폰에서도 됩니다.
어떤 브라우저에서 쓸 수 있나요?
Google Chrome 116 이상과 Microsoft Edge에서 9개 언어로 쓸 수 있습니다.
페이지의 모든 이미지를 한 번에 저장할 수 있나요?
아니요. Imgkeep은 오른쪽 버튼으로 클릭한 이미지 하나를 저장합니다. 페이지 전체를 받으려면 일괄 다운로더가 필요합니다.
