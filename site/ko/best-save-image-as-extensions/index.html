2026년 11월 24일에 Chrome 웹 스토어, Edge 추가 기능, Firefox 부가 기능에서 'save image as', 'save image as type', 'webp to png'를 검색해, 이미지를 다른 형식으로 저장하는 것이 주된 기능인 확장 프로그램 중 가장 눈에 띄는 것들을 골랐습니다. 일괄 다운로더와 역방향 이미지 검색은 제외했습니다. Imgkeep은 저희 제품입니다. 각 게시자가 밝힌 내용만 싣기 때문에, 대시는 할 수 없다는 뜻이 아니라 게시자가 밝히지 않았다는 뜻입니다.

안전한 확장 프로그램 고르는 법

어떤 것을 고르든 몇 분 확인해 볼 가치가 있습니다. 이미지 저장 도구는 오른쪽 클릭한 페이지를 볼 수 있고, 확장 프로그램은 팔린 뒤에 바뀔 수 있기 때문입니다.

  1. 권한. '모든 웹사이트에서 내 데이터 읽기 및 변경'은 방문하는 모든 페이지를 볼 수 있다는 뜻입니다. 오른쪽 클릭한 이미지를 저장하는 데는 필요 없습니다.
  2. 데이터. 스토어 페이지의 개인정보 보호 항목을 읽어 보세요. 무엇을 수집한다고 하나요?
  3. 소유자와 업데이트. 누가 게시하는지 확인하고, 업데이트가 갑자기 새 권한을 요구하면 주의하세요.
  4. 소스 코드. 코드가 공개되어 있으면 다른 사람들이 무엇을 하는지 확인할 수 있습니다.

전체 체크리스트와 원래 Save image as Type에 무슨 일이 있었는지는 Save image as Type의 안전한 대안에 있습니다.

필요에 따라 다릅니다. 페이지 전체의 이미지를 저장하려면 일괄 저장을 지원하는 것을 고르세요. 오른쪽 클릭한 이미지를 원하는 형식으로 업로드 없이 저장하려면 여기 있는 이미지 한 장씩 저장하는 확장 프로그램 어느 것이든 됩니다. 형식, 권한, 코드 공개 여부를 비교해 보세요.

이 확장 프로그램들은 안전한가요?

저희가 대신 판단하지는 않습니다. 표에는 각 확장 프로그램 자체의 스토어 페이지나 패키지를 기준으로 요청하는 권한과 코드 공개 여부를 실었습니다. 각 스토어 페이지의 개인정보 보호 항목도 확인하고, 이미지 확장 프로그램이 안전한지 확인하는 법도 참고하세요.

왜 '밝히지 않음'이라고 적힌 칸이 있나요?

각 게시자가 스토어 페이지, 웹사이트, 패키지, 코드에서 밝힌 내용만 싣습니다. '밝히지 않음'은 게시자가 그에 대해 아무 말도 하지 않았다는 뜻이지, 확장 프로그램이 할 수 없다는 뜻이 아닙니다.
