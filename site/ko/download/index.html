휴대폰이나 태블릿을 쓰고 계신가요?

확장 프로그램은 데스크톱 브라우저용입니다. 휴대폰에서는 무료 이미지 변환기로 이미 가지고 있는 이미지를 업로드 없이 브라우저에서 바로 변환할 수 있습니다.

질문

Imgkeep은 무료인가요?
네. Imgkeep은 무료 오픈 소스(MIT)이며 계정도, 광고도, 사용 제한도 없습니다. 지금 제공되는 모든 기능은 계속 무료입니다.
Imgkeep은 어떤 브라우저에서 쓸 수 있나요?
Google Chrome(Windows, macOS, Linux, ChromeOS)과 Microsoft Edge(Windows, macOS, Linux)에서 사용할 수 있습니다. Firefox 버전은 Mozilla에서 검토 중이며 승인되면 여기에 올라갑니다.
Imgkeep은 모든 브라우저에서 똑같이 작동하나요?
거의 같습니다. Firefox는 직접 지정한 폴더에 파일을 쓸 수 없어서, 이미지는 다운로드 폴더에 저장되거나 저장할 때마다 위치를 선택하게 됩니다. 또 익명 일일 사용 요약은 설치할 때 허용하지 않는 한 Firefox에서는 꺼져 있습니다.
휴대폰에서도 Imgkeep을 쓸 수 있나요?
확장 프로그램은 데스크톱 브라우저용입니다. 휴대폰이나 태블릿에서는 imgkeep.app의 무료 이미지 변환기를 사용하세요. 업로드 없이 브라우저에서 이미지를 변환합니다.

필요한 기능이 없나요? 아이디어 보드에 제안해 주세요. Imgkeep이 데이터를 다루는 방식은 개인정보처리방침에서 확인하세요.
