Chrome이 이미지를 WebP로 저장하는 이유(그리고 JPG나 PNG로 받는 방법)

간단한 답변

Chrome은 웹사이트가 보낸 파일을 그대로 저장합니다. 그리고 요즘 많은 사이트는 같은 품질에서 JPG나 PNG보다 용량이 작은 WebP를 보냅니다. Chrome에는 이를 바꾸는 설정이 없습니다. JPG나 PNG로 받으려면 이미지를 변환해야 합니다. 저장하면서 확장 프로그램으로 변환하거나, 저장한 뒤 Paint(Windows)나 Preview(Mac)에서 변환하세요.

업데이트: 2026년 10월 28일

Chrome은 왜 이미지를 WebP로 저장하나요?

Chrome은 사이트에 이미지를 요청할 때마다 자신이 표시할 수 있는 형식도 함께 알려줍니다. 최신 Chrome은 AVIF와 WebP를 가장 앞에 적습니다. 많은 사이트와 이미지 서비스는 이를 보고 가장 작은 파일을 골라 보냅니다. 같은 품질이라면 WebP와 AVIF가 JPG나 PNG보다 훨씬 작기 때문입니다. 그만큼 페이지도 빨리 열립니다.

이미지를 다른 이름으로 저장…을 선택하면 Chrome은 받은 파일을 그대로 저장합니다. 아무것도 변환하지 않습니다. 여기서 두 가지가 따라옵니다.

  • 이미지 주소가 .jpg로 끝나도 실제로는 WebP가 올 수 있습니다. 사이트는 파일 이름이 아니라 브라우저가 받아들이는 형식을 보고 결정합니다.
  • 같은 이미지가 AVIF로 올 수도 있습니다. AVIF를 JPG나 PNG로 저장하는 방법을 참고하세요.
  • Windows에서는 JPG가 .jfif로 저장되기도 합니다. 이건 이름만의 문제입니다. Chrome이 이미지를 JFIF로 저장하는 경우를 보세요.

이를 막는 Chrome 설정이 있나요?

없습니다. Chrome에는 저장할 이미지 형식을 정하는 옵션도, WebP를 원하지 않는다고 사이트에 알리는 설정도 없습니다. 그래서 아래 방법들은 모두 이미지 자체를 다룹니다. 저장하면서 변환하거나, 저장한 뒤에 변환하는 것입니다.

대신 JPG나 PNG로 받으려면 어떻게 하나요?

이미 WebP를 저장하셨나요? 가지고 있는 파일을 업로드 없이 브라우저에서 변환하세요. WebP를 JPG로.

1. 복사해서 이미지 편집기에 붙여넣기

이미지를 오른쪽 클릭하고 이미지 복사를 선택하세요. Windows에서는 Paint에 붙여넣고(Ctrl+V) 파일 › 다른 이름으로 저장을 사용합니다. Mac에서는 Preview를 열어 파일 › 클립보드에서 새로 만들기를 고른 뒤 파일 › 내보내기를 선택합니다. 따로 설치할 것은 없습니다. 단점은 이미지마다 여러 단계를 거쳐야 하고, 투명 배경이 사라질 수 있다는 점입니다.

2. 저장한 뒤 변환하기

WebP를 평소처럼 저장하고 Paint(Windows)나 Preview(Mac)에서 연 다음 JPEG나 PNG로 저장하거나 내보내세요. 이 방법도 설치할 것은 없지만, 파일이 두 개가 되고 매번 클릭 몇 번이 더 듭니다. 단계별 안내: WebP를 JPG나 PNG로 저장하는 방법.

3. 스크린샷 찍기

Windows에서는 Win+Shift+S, Mac에서는 Cmd+Shift+4를 누르고 이미지 영역을 선택하세요. 화면에 보이는 것이라면 무엇이든 가능합니다. 단점은 원본 파일이 아니라 화면에 보이는 것을 얻는다는 점입니다. 그래서 크기가 작아지고 페이지의 일부가 함께 담기기도 합니다. 오른쪽 클릭 메뉴에 이미지 항목 자체가 없다면 오른쪽 클릭으로 이미지가 저장되지 않을 때를 보세요.

4. 저장하면서 변환해 주는 확장 프로그램 쓰기

확장 프로그램은 오른쪽 클릭 메뉴에 "PNG나 JPG로 저장" 항목을 추가해 원본 크기 그대로 한 번에 변환해 줍니다. 단점은 브라우저에서 실행되는 코드를 신뢰해야 한다는 점이니 신중하게 고르세요(아래 체크리스트 참고).

저희 확장 프로그램

Imgkeep

저희는 바로 이 용도의 무료 Chrome 확장 프로그램 Imgkeep을 만듭니다. 아무 이미지나 오른쪽 클릭하고 Imgkeep을 선택한 다음 PNG, JPG, WebP, GIF, PDF 또는 원본 형식을 고르세요. 변환은 내 컴퓨터에서 이뤄지고, 다운로드 폴더나 직접 고른 폴더, 또는 매번 선택하는 위치에 저장됩니다. 페이지에서 이미지를 찾아 달라고 할 때만 그 페이지를 확인하고, 페이지를 바꾸는 일은 없으며, 오픈 소스입니다.

Chrome에 Imgkeep 추가 — 무료 권한은 네 개. 업로드도, 계정도 없습니다.

이미지 확장 프로그램은 어떻게 판단하나요?

오래된 글에서는 "Save image as Type"을 자주 추천합니다. 이 확장 프로그램은 소유자가 바뀐 뒤 쇼핑 사이트에 제휴 링크를 심는 것이 발견되어 2026년 3월 Google이 Chrome Web Store에서 삭제했습니다(9to5Google). 아직 설치되어 있다면 삭제하세요. 무엇을 설치하든 다음을 확인하세요.

  • 권한. 모든 웹사이트에서 "모든 데이터 읽기 및 변경"을 요구하나요? 오른쪽 클릭한 이미지를 저장하는 데는 그런 권한이 필요 없습니다.
  • 데이터. 스토어 등록 정보의 "개인정보 보호" 항목을 읽어 보세요. 무언가를 수집한다고 되어 있나요?
  • 소유자와 업데이트. 지금도 관리되고 있나요? 최근에 개발자가 바뀌지는 않았나요?
  • 소스 코드. 코드가 공개되어 있어 다른 사람들이 동작을 확인할 수 있나요?

전체 체크리스트와 Save image as Type에 무슨 일이 있었는지: Save image as Type의 안전한 대안.

질문

.webp 파일 이름을 .jpg로 바꾸면 되지 않나요?

이름을 바꿔도 파일 자체는 바뀌지 않습니다. 내용은 여전히 WebP입니다. 어떤 앱은 내용을 확인해 그냥 열어 주지만, 많은 앱은 그렇지 않습니다. 이름을 바꾸는 대신 변환하세요.

WebP는 나쁜 형식인가요?

아닙니다. 페이지를 더 빠르게 불러오게 해 주는 좋은 형식이고, 요즘 브라우저와 운영체제는 모두 표시할 수 있습니다. 문제는 아직 JPG나 PNG를 기대하는 오래된 앱, 일부 업로드 양식, 일부 인쇄·디자인 도구입니다.

JPG와 PNG 중 무엇을 고를까요?

PNG는 모든 픽셀과 투명도를 그대로 유지하지만 파일이 더 큽니다. JPG는 파일이 작고 사진에 적합하지만 투명도를 지원하지 않습니다. 자세한 내용은 WebP 안내를 보세요.
