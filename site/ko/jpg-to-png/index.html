JPG → PNG 변환기

PNG를 요구하는 앱이나 양식에 맞게 JPG를 PNG로 바꾸세요. 업로드할 필요가 없습니다.

선택한 출력 형식: PNG

비워 두면 원본 크기를 유지합니다. 더 작은 이미지는 확대되지 않습니다.

    로컬 변환이 작동하는 방식

    이미지는 Imgkeep 확장 프로그램과 같은 코드로, 이 페이지에서 사용자의 기기에서 변환됩니다. 업로드되는 것은 없습니다. 사이트는 페이지 조회수와 어떤 형식을 파일 몇 개로 변환했는지(예: "webp → jpg, 파일 3개")만 집계하며, 이미지 내용이나 파일 이름, 파일 크기는 전송하지 않습니다.

    • 이 페이지를 연 뒤 Wi-Fi를 꺼 보세요. AVIF를 제외한 모든 형식의 변환이 그대로 작동합니다. AVIF 인코더는 처음 선택할 때 불러옵니다.
    • 브라우저 개발자 도구를 열고 네트워크 탭에서 파일을 변환해 보세요. 어떤 요청에도 이미지가 담기지 않습니다.
    • 코드는 공개되어 있습니다. GitHub의 site/convert와, 변환이 네트워크 요청을 전혀 보내지 않고 오프라인에서도 작동하는지 확인하는 테스트를 보세요.

    간단한 답변

    위에 JPG를 끌어다 놓고 PNG를 선택한 채로 PNG 파일을 내려받으세요. 브라우저에서 처리되므로 아무것도 업로드되지 않습니다. PNG는 JPG의 모든 픽셀을 그대로 보존하므로 나중에 편집해도 더 잃는 것이 없습니다. 다만 JPG가 이미 잃은 디테일을 되살리지는 못하고, 파일은 보통 더 큽니다. JPG에는 투명도가 없으므로 PNG에도 투명도가 없습니다.

    업데이트: 2026년 11월 25일

    JPG를 PNG로 변환하는 이유는?

    일부 앱, 업로드 양식, 인쇄 서비스는 PNG를 요구합니다. 이미지를 여러 번 편집할 예정이라면 PNG가 더 나은 작업용 사본이기도 합니다. JPG는 저장할 때마다 다시 압축되지만 PNG는 보이는 그대로 저장됩니다.

    JPG와 PNG 비교

    형식JPGPNG
    압축손실: 작은 사진 파일무손실: 모든 픽셀 보존
    투명도없음(색으로 채워짐)있음, 부드러운 가장자리까지
    애니메이션없음일반 PNG에는 없음
    열리는 곳모든 앱, 브라우저, 업로드 양식모든 앱과 브라우저

    PNG가 화질이 더 좋아지나요?

    JPG보다 좋아지지도 나빠지지도 않습니다. PNG는 압축으로 생긴 흐림이나 블록 현상까지 포함해 JPG의 픽셀을 그대로 저장합니다. 원본 사진이 있다면 그것을 변환하세요.

    PNG가 왜 이렇게 큰가요?

    PNG는 아무것도 버리지 않고 압축하므로 그래픽과 스크린샷에는 맞지만 사진에는 맞지 않습니다. 사진을 PNG로 저장하면 JPG보다 3~5배 커지는 경우가 많습니다. 파일을 줄이려면 고급 옵션에서 최대 너비를 정하고, 파일을 작게 유지하려면 JPG를 그대로 쓰세요.

    배경을 투명하게 만들 수 있나요?

    변환기로는 안 됩니다. JPG에는 투명한 영역이 없어서 보존할 것이 없습니다. 배경을 지우려면 이미지 편집기가 필요합니다. 이미 투명도가 있는 로고라면 PNG, SVG, WebP 버전에서 시작하세요.

    질문

    JPG를 PNG로 변환하면 무손실인가요?

    변환 자체는 무손실입니다. PNG에는 JPG의 픽셀이 정확히 담깁니다. 하지만 JPG가 처음 저장될 때 잃은 것은 되살릴 수 없습니다.

    PNG를 다시 JPG로 바꿀 수 있나요?

    네, PNG를 JPG로에서 공유하기 좋은 더 작은 파일로 바꿀 수 있습니다.

    JPG 여러 장을 한 번에 변환할 수 있나요?

    네, 한 번에 최대 20장, 파일당 50 MB까지 됩니다. 하나씩 또는 한꺼번에 내려받으세요.
