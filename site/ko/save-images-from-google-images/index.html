Google 이미지에서 원본 크기 이미지를 저장하는 방법

간단한 답변

Google 이미지 그리드의 그림은 Google이 만든 폭 수백 픽셀의 작은 사본이라서, 저장하면 썸네일이 됩니다. 먼저 이미지를 클릭하세요. 미리보기가 원래 웹사이트에서 전체 이미지를 불러오며, 그건 저장할 수 있습니다. 가장 좋은 사본을 얻고 다시 써도 되는지 확인하려면 '방문'을 클릭해 원본 페이지에서 저장하세요.

업데이트: 2026년 11월 24일

Google 이미지의 동작은 2026년 11월 24일에 Chrome의 google.com에서 확인했습니다. Google은 레이아웃을 자주 바꿉니다. 다르게 보이면 helloimgkeep@gmail.com(으)로 알려 주세요.

Google에서 저장한 이미지가 왜 이렇게 작나요?

결과 그리드의 그림은 Google이 직접 만들어 저장한 썸네일로, 주소가 encrypted-tbn0.gstatic.com으로 시작합니다. 크기는 수백 픽셀입니다. 오른쪽 클릭은 되므로 다른 이름으로 이미지 저장이 나오지만, 저장되는 건 그 썸네일입니다.

결과를 클릭하면 Google이 미리보기를 열고 이미지를 게시한 웹사이트에서 불러옵니다. 잠깐 흐린 썸네일이 보이다가, 선명한 버전이 나타나면 그게 전체 이미지입니다.

확장 프로그램 없이 전체 이미지를 저장하려면?

  1. 결과에서 이미지를 클릭해 미리보기를 열고, 선명해질 때까지 기다리세요.
  2. 큰 이미지를 오른쪽 클릭하고 다른 이름으로 이미지 저장을 선택하세요. 아직 흐릴 때 저장하면 썸네일이 저장됩니다.
  3. 더 좋은 방법은 방문을 클릭해 원본 페이지를 열고 거기서 저장하는 것입니다. 누가 만들었는지, 다시 써도 되는지 알 수 있습니다.

다시 쓸 수 있는 이미지를 찾으려면 이미지 탭에서 도구 → 사용 권한 → 크리에이티브 커먼즈 라이선스를 쓰고, 원본 페이지에서 라이선스를 확인하세요. 많은 사이트가 WebP나 AVIF를 보냅니다. WebP를 JPG나 PNG로, AVIF를 JPG나 PNG로를 보세요.

Imgkeep으로 저장하려면?

Imgkeep은 마우스 오른쪽 버튼 메뉴에서 이미지를 PNG, JPG, WebP, GIF, PDF로 저장하는 브라우저 확장 프로그램입니다. 저희가 만듭니다. Google 이미지 측과 제휴하지 않았으며 Google 이미지 측의 보증을 받지도 않았습니다.

  1. 결과를 클릭해 선명한 이미지를 기다린 뒤, 오른쪽 클릭하고 Imgkeep → JPG 또는 PNG를 선택하세요. 원본 사이트의 WebP나 AVIF 이미지는 저장할 때 변환되어, 어떤 앱에서나 열리는 파일이 됩니다.
  2. 문서나 디자인 도구에 붙여 넣으려면 PNG로 복사를 선택하세요.
  3. 또는 큰 이미지를 가리키고 Alt+S(Mac에서는 Option+S, Firefox에서는 Alt+Shift+S)를 누르면 마지막으로 쓴 형식으로 저장됩니다.

Imgkeep은 페이지에 표시된 이미지를 저장하므로, 미리보기가 다 불러와질 때까지 기다리세요. Google에서는 '여기서 이미지 찾기'가 필요 없습니다. 오른쪽 클릭이 이미 이미지에 닿습니다.

저희 확장 프로그램

Imgkeep

오른쪽 클릭한 이미지를 PNG, JPG, WebP, GIF(애니메이션 유지), PDF로 저장하거나 PNG로 복사하세요. 폴더와 파일 이름을 정하고, 사이트가 덮어 둔 이미지도 찾을 수 있습니다. 컴퓨터에서 변환: 업로드 없음, 계정 없음.

Chrome에 Imgkeep 추가 — 무료 Edge와 Firefox에서도 사용할 수 있습니다. Alt+S는 0.15 이상 버전이 필요합니다.

저장한 이미지를 사용해도 되나요?

나중에 보려고, 무드보드나 개인 참고용으로 이미지를 저장하는 것과 그것을 다시 쓰는 것은 다릅니다. 이미지는 만든 사람의 것이며, 그곳에 올라온 콘텐츠에는 Google의 약관이 적용됩니다. 이미지를 게시·인쇄·판매하기 전에 제작자에게 허락을 받고 출처를 밝히세요. 이미 볼 수 있는 것만 저장하세요. Imgkeep은 로그인, 비공개 계정, 유료 장벽을 우회하지 않으며, 그런 용도가 아닙니다.

질문

Google 이미지에서 작고 흐린 그림이 저장되는 이유는?

결과 그리드의 썸네일을 저장했기 때문입니다. 이미지를 클릭해 미리보기에서 선명한 버전을 기다린 뒤 저장하거나, 원본 페이지에서 저장하세요.

Google에서 찾은 이미지를 써도 되나요?

Google에 보인다고 해서 쓸 수 있는 건 아닙니다. 모든 이미지는 만든 사람의 것입니다. 크리에이티브 커먼즈 이미지는 '사용 권한' 필터로 찾고, 원본 페이지에서 라이선스를 확인하세요.

Google 이미지가 WebP로 저장되는 이유는?

이미지는 그것을 게시한 웹사이트에서 오고, 많은 사이트가 WebP를 보냅니다. 변환기로 JPG나 PNG로 저장하거나, WebP를 JPG나 PNG로 저장하는 방법을 보세요.
