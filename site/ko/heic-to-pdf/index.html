HEIC → PDF 변환기

iPhone으로 찍은 서류, 영수증, 신분증 사진을 PDF로 바꾸세요. 업로드할 필요가 없습니다.

01 출력 형식 선택

선택한 출력 형식: PNG

PNG는 투명도를 유지합니다.

비워 두면 원본 크기를 유지합니다. 더 작은 이미지는 확대되지 않습니다.

1600처럼 픽셀 단위 정수를 입력하세요.

92

낮출수록 파일이 작아집니다.

이미지에서 투명한 부분에 사용됩니다.

#FFFFFF 같은 색상 값을 입력하세요.

또는 이미지 붙여넣기 (⌘V / Ctrl+V)

내 이미지

    웹 페이지에서 이미지를 저장하나요? 무료 확장 프로그램을 설치하면 오른쪽 클릭 한 번이면 됩니다.

    익명 페이지 조회수와 변환 횟수만 집계합니다. 이미지나 파일 이름, 파일 크기는 전송하지 않습니다. 개인정보 보호 ↗

    로컬 변환이 작동하는 방식

    이미지는 Imgkeep 확장 프로그램과 같은 코드로, 이 페이지에서 사용자의 기기에서 변환됩니다. 업로드되는 것은 없습니다. 사이트는 페이지 조회수와 어떤 형식을 파일 몇 개로 변환했는지(예: "webp → jpg, 파일 3개")만 집계하며, 이미지 내용이나 파일 이름, 파일 크기는 전송하지 않습니다.

    • 이 페이지를 열고 사진을 하나 추가한 뒤 Wi-Fi를 꺼 보세요. 변환은 계속 됩니다. (Chrome, Edge, Firefox에서는 첫 사진과 함께 HEIC 디코더를 불러오며, Safari에는 필요 없습니다.)
    • 브라우저 개발자 도구를 열고 네트워크 탭에서 파일을 변환해 보세요. 어떤 요청에도 이미지가 담기지 않습니다.
    • 코드는 공개되어 있습니다. GitHub의 site/convert와, 변환이 네트워크 요청을 전혀 보내지 않고 오프라인에서도 작동하는지 확인하는 테스트를 보세요.

    간단한 답변

    위에 HEIC 사진을 끌어다 놓고 PDF를 선택한 다음, 사진마다 사진과 똑같은 크기에 올바른 방향인 PDF를 하나씩 내려받으세요. Chrome, Edge, Firefox에서는 페이지가 먼저 HEIC 디코더(약 0.5 MB)를 불러오며, Safari는 HEIC를 직접 엽니다. 모든 처리가 브라우저에서 이루어지므로 아무것도 업로드되지 않습니다. 신분증이나 영수증이라면 특히 중요한 점입니다.

    업데이트: 2026년 11월 25일

    iPhone 사진을 PDF로 바꾸는 이유는?

    양식과 기관은 서류를 PDF로 요구하는 경우가 많고, HEIC는 아예 열지 못하는 곳도 많습니다. iPhone으로 영수증이나 신분증을 찍으면 HEIC 파일이 되는데, 이 페이지에서 어디서나 열리는 PDF로 바꿀 수 있습니다.

    신분증이나 은행 서류에 써도 될 만큼 안전한가요?

    사진은 기기를 벗어나지 않습니다. 페이지가 브라우저에서 사진을 읽고 변환하며, 디코더를 한 번 불러오면 오프라인에서도 계속 작동합니다. 서버로는 아무것도 전송되지 않습니다. Live Photo 동영상이나 심도 데이터는 제외하고 메인 사진만 변환합니다.

    PDF를 작게 유지하려면?

    iPhone 사진은 너비가 4000픽셀에 이르는 경우가 많을 만큼 큽니다. 고급 옵션에서 최대 너비를 2000 정도로 정하세요. 서류는 그대로 읽히고 PDF는 훨씬 작아집니다. 인쇄할 때는 인쇄 창에서 '페이지에 맞춤'을 선택하세요.

    질문

    사진 여러 장을 PDF 하나로 합칠 수 있나요?

    여기서는 안 됩니다. 사진마다 PDF가 따로 만들어집니다. 파일 병합이 되는 PDF 리더나 편집기로 합칠 수 있습니다.

    iPhone에서도 되나요?

    네, iPhone과 iPad의 Safari에서 됩니다. Safari에서는 추가 디코더 없이 HEIC가 열립니다.

    JPG로 받으려면요?

    서류가 아니라 공유할 사진이라면 HEIC를 JPG로에서 어떤 앱이든 여는 더 작은 파일을 얻을 수 있습니다.

    웹에서 바로 이미지를 저장하세요.

    Chrome, Edge, Firefox용 Imgkeep을 쓰면 이미지를 오른쪽 클릭할 때 형식을 고를 수 있습니다. 나중에 따로 변환할 파일이 생기지 않습니다.
