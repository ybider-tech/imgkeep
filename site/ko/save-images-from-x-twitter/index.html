X (Twitter)에서 이미지를 저장하는 방법

간단한 답변

X에서는 모든 사진이 게시물로 가는 링크 아래에 있어서, 오른쪽 클릭하면 '다른 이름으로 이미지 저장' 대신 링크 항목이 나옵니다. 이미지 주소가 크기도 정하는데, name=small이나 name=large 같은 식입니다. 이미지 주소를 열어 name=orig로 바꾸고 저장하세요. Imgkeep에서는 '여기서 이미지 찾기'나 Alt+S를 쓰고, 원본을 받으려면 '원본 크기 버전 저장'을 켜세요.

업데이트: 2026년 11월 24일

X의 동작은 2026년 11월 24일에 Chrome의 x.com에서 확인했습니다. X 사이트는 자주 바뀝니다. 다르게 보이면 helloimgkeep@gmail.com(으)로 알려 주세요.

X 이미지를 오른쪽 클릭으로 저장할 수 없는 이유는?

X는 게시물의 모든 사진 위에 링크를 올려 두어서, 오른쪽 클릭이 링크에 닿고 메뉴에는 다른 이름으로 이미지 저장이 아니라 새 탭에서 링크 열기 같은 항목이 나옵니다.

이미지는 pbs.twimg.com에서 오고, 주소 끝부분이 크기와 형식을 정합니다. 예: ?format=jpg&name=small, medium, large. name=orig은 업로드 크기를 요청합니다.

X의 움직이는 'GIF'는 사실 짧은 동영상이라서, Imgkeep을 포함한 이미지 도구로는 이미지로 저장할 수 없습니다.

확장 프로그램 없이 X 이미지를 저장하려면?

  1. 사진을 오른쪽 클릭하고 검사를 선택하세요. 강조된 링크 옆에서 주소가 pbs.twimg.com/media/로 시작하는 <img>를 찾으세요.
  2. 그 주소를 새 탭에서 열고 name=small(또는 medium, large)을 name=orig로 바꾸세요.
  3. 그 탭에서 이미지를 저장하세요. JPG가 필요하면 format=webp를 format=jpg로 바꾸세요.

또는 스크린샷을 찍으세요. 화면에 보이는 크기로 저장됩니다.

Imgkeep으로 저장하려면?

Imgkeep은 마우스 오른쪽 버튼 메뉴에서 이미지를 PNG, JPG, WebP, GIF, PDF로 저장하는 브라우저 확장 프로그램입니다. 저희가 만듭니다. X 측과 제휴하지 않았으며 X 측의 보증을 받지도 않았습니다.

  1. 사진을 오른쪽 클릭하고 Imgkeep: 여기서 이미지 찾기…를 선택하세요. Imgkeep이 링크 아래의 이미지를 찾아 추가 옵션에서 엽니다. JPG, PNG 등 형식을 고른 뒤 저장이나 PNG로 복사를 누르세요.
  2. 또는 사진을 가리키고 Alt+S(Mac에서는 Option+S, Firefox에서는 Alt+Shift+S)를 누르면 마지막으로 쓴 형식으로 저장됩니다.
  3. 옵션에서 원본 크기 버전 저장을 켜면 Imgkeep이 X 이미지 서비스에 업로드 크기인 name=orig을 요청하고, 받지 못하면 클릭한 이미지를 저장합니다.

'여기서 이미지 찾기'는 페이지에 이미 표시된 이미지만 찾습니다. 켜기 전까지는 꺼져 있고, Imgkeep은 요청할 때만 페이지를 봅니다.

저희 확장 프로그램

Imgkeep

오른쪽 클릭한 이미지를 PNG, JPG, WebP, GIF(애니메이션 유지), PDF로 저장하거나 PNG로 복사하세요. 폴더와 파일 이름을 정하고, 사이트가 덮어 둔 이미지도 찾을 수 있습니다. 컴퓨터에서 변환: 업로드 없음, 계정 없음.

Chrome에 Imgkeep 추가 — 무료 Edge와 Firefox에서도 사용할 수 있습니다. Alt+S는 0.15 이상 버전이 필요합니다.

저장한 이미지를 사용해도 되나요?

나중에 보려고, 무드보드나 개인 참고용으로 이미지를 저장하는 것과 그것을 다시 쓰는 것은 다릅니다. 이미지는 만든 사람의 것이며, 그곳에 올라온 콘텐츠에는 X의 약관이 적용됩니다. 이미지를 게시·인쇄·판매하기 전에 제작자에게 허락을 받고 출처를 밝히세요. 이미 볼 수 있는 것만 저장하세요. Imgkeep은 로그인, 비공개 계정, 유료 장벽을 우회하지 않으며, 그런 용도가 아닙니다.

질문

X 이미지를 원본 크기로 저장하려면?

이미지 주소를 열어 name=small이나 name=large를 name=orig로 바꾸세요. Imgkeep에서는 '원본 크기 버전 저장'을 켜면 원본을 대신 요청합니다.

X에서 오른쪽 클릭하면 링크 항목이 나오는 이유는?

X가 모든 사진 위에 게시물 링크를 올려 두어서, 오른쪽 클릭이 이미지가 아니라 링크에 닿기 때문입니다.

X의 GIF를 저장할 수 있나요?

이미지로는 안 됩니다. X의 GIF는 짧은 동영상이라서, 이미지 저장 도구로는 GIF 파일로 저장할 수 없습니다.
