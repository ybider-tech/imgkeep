    이미지를 업로드하지 않고 색상 팔레트를 얻으려면?

    이 페이지에 이미지를 끌어다 놓으면 주요 색상 5개, 8개, 12개를 비중이 큰 순서대로 각 색상의 비율과 함께 보여 줍니다. 색상을 클릭하면 HEX, RGB, HSL 값을 복사할 수 있고, 전체를 CSS 변수나 Tailwind 형식으로 한 번에 복사할 수도 있습니다. 이미지는 브라우저에서 읽으며 업로드되지 않습니다. 가입도 광고도 없습니다.

    업데이트: 2026년 10월 28일

    색상은 어떻게 고르나요?

    이미지를 긴 쪽 기준 200픽셀로 줄인 뒤, 투명한 픽셀은 빼고 나머지를 눈에 보이는 색의 유사도에 따라 묶습니다(Lab 색 공간의 k-평균 군집화). 거의 같아 보이는 색은 하나로 셉니다. 같은 이미지는 언제나 같은 팔레트를 냅니다.

    팔레트로 무엇을 할 수 있나요?

    출력사용할 곳

    .aseIllustrator, Photoshop, InDesign

    이미지 자체를 다른 형식으로 바꾸고 싶다면 무료 이미지 변환기를 쓰세요.

    제한 사항

    • 한 번에 이미지 한 장.
    • 애니메이션 GIF, WebP, APNG는 첫 프레임만.
    • 완전히 투명한 이미지에는 가져올 색상이 없습니다.
    • HEIC 사진(iPhone에서 찍은 사진)은 Chrome, Edge, Firefox에서 열 수 없습니다.

    웹 페이지 속 이미지의 색상 가져오기

    Chrome과 Edge용 Imgkeep 확장 프로그램을 쓰면 파일을 먼저 저장할 필요 없이 마우스 오른쪽 버튼 클릭 한 번으로 끝납니다. 이미지를 오른쪽 버튼으로 클릭하고 Imgkeep, 색상 팔레트 보기를 선택하세요. Instagram이나 Pinterest처럼 사진을 다른 레이어 아래에 감춰 두는 사이트에서도 작동합니다.

    질문

    이 색상 팔레트 도구는 무료인가요?

    네. 계정도, 제한도, 워터마크도, 광고도 없습니다.

    제 이미지가 업로드되나요?

    아니요. 색상은 브라우저에서 계산하며 이미지는 기기를 벗어나지 않습니다. 이 페이지는 페이지 조회 횟수와 스토어 링크를 따라간 횟수를 익명으로 한 번씩 보낼 뿐, 이미지나 색상, 파일 이름은 절대 보내지 않습니다.

    왜 선택한 개수보다 색상이 적게 나오나요?

    이미지에 서로 다른 색이 그만큼 없기 때문입니다. 거의 같아 보이는 색은 하나로 합쳐지므로, 단색 세 가지로 된 로고는 8개를 요청해도 세 가지만 나옵니다.

    어떤 형식으로 복사하거나 저장할 수 있나요?

    각 색상은 HEX, RGB, HSL로 복사할 수 있습니다. 팔레트 전체는 CSS 변수, Tailwind 색상 코드, JSON, 일반 목록으로 복사할 수 있고, 파일로는 PNG 색상표, GIMP 팔레트(.gpl, Inkscape와 Krita에서도 열립니다), Adobe 스와치(.ase, Illustrator·Photoshop·InDesign용)로 저장할 수 있습니다.

    웹 페이지에 있는 이미지의 팔레트도 볼 수 있나요?

    네, Chrome과 Edge용 무료 Imgkeep 확장 프로그램을 쓰면 됩니다. 이미지를 마우스 오른쪽 버튼으로 클릭하고 Imgkeep, 색상 팔레트 보기를 선택하세요. 사진이 다른 레이어 아래에 놓이는 Instagram, Pinterest 같은 사이트에서는 Imgkeep: 여기서 이미지 찾기…를 고른 다음 추가 옵션, 색상 팔레트 보기를 선택하세요.

    휴대폰에서도 작동하나요?

    네, 모바일 브라우저에서도 됩니다. Imgkeep 확장 프로그램은 데스크톱용 Chrome과 Edge에서 쓸 수 있습니다.

    웹에서 바로 색상을 가져오세요.

    Chrome이나 Edge에서 Imgkeep을 써 보세요. 이미지를 마우스 오른쪽 버튼으로 클릭해 팔레트를 보거나, 필요한 형식으로 저장할 수 있습니다.

    무료 확장 프로그램 받기 Edge용도 있습니다
