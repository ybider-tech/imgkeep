JPG → PDF 변환기

사진이나 스캔 이미지로 양식이나 이메일에 쓸 PDF를 만드세요. 업로드할 필요가 없습니다.

01 출력 형식 선택

선택한 출력 형식: PNG

PNG는 투명도를 유지합니다.

비워 두면 원본 크기를 유지합니다. 더 작은 이미지는 확대되지 않습니다.

1600처럼 픽셀 단위 정수를 입력하세요.

92

낮출수록 파일이 작아집니다.

이미지에서 투명한 부분에 사용됩니다.

#FFFFFF 같은 색상 값을 입력하세요.

또는 이미지 붙여넣기 (⌘V / Ctrl+V)

내 이미지

    웹 페이지에서 이미지를 저장하나요? 무료 확장 프로그램을 설치하면 오른쪽 클릭 한 번이면 됩니다.

    익명 페이지 조회수와 변환 횟수만 집계합니다. 이미지나 파일 이름, 파일 크기는 전송하지 않습니다. 개인정보 보호 ↗

    로컬 변환이 작동하는 방식

    이미지는 Imgkeep 확장 프로그램과 같은 코드로, 이 페이지에서 사용자의 기기에서 변환됩니다. 업로드되는 것은 없습니다. 사이트는 페이지 조회수와 어떤 형식을 파일 몇 개로 변환했는지(예: "webp → jpg, 파일 3개")만 집계하며, 이미지 내용이나 파일 이름, 파일 크기는 전송하지 않습니다.

    • 이 페이지를 연 뒤 Wi-Fi를 꺼 보세요. AVIF를 제외한 모든 형식의 변환이 그대로 작동합니다. AVIF 인코더는 처음 선택할 때 불러옵니다.
    • 브라우저 개발자 도구를 열고 네트워크 탭에서 파일을 변환해 보세요. 어떤 요청에도 이미지가 담기지 않습니다.
    • 코드는 공개되어 있습니다. GitHub의 site/convert와, 변환이 네트워크 요청을 전혀 보내지 않고 오프라인에서도 작동하는지 확인하는 테스트를 보세요.

    간단한 답변

    위에 JPG를 끌어다 놓고 PDF를 선택한 다음 이미지마다 PDF를 하나씩 내려받으세요. 각 PDF는 여백 없이 사진과 똑같은 크기의 한 페이지이며, 사진은 설정한 JPG 품질로 PDF 안에 JPEG으로 저장됩니다. 브라우저에서 처리되므로 아무것도 업로드되지 않고 가입도 필요 없습니다. 이미지가 여러 장이면 PDF도 여러 개가 되며 하나로 합쳐지지 않습니다.

    업데이트: 2026년 11월 25일

    JPG 대신 PDF가 필요한 경우는?

    많은 신청 양식, 정부 사이트, 문서 시스템은 신분증이나 영수증 스캔이라도 PDF만 받습니다. PDF는 정해진 크기로 인쇄되고, 어떤 컴퓨터와 휴대폰에서도 똑같이 열립니다.

    JPG와 PDF 비교

    형식JPGPDF
    압축손실: 작은 사진 파일이미지를 담은 문서 페이지
    투명도없음(색으로 채워짐)유지됨
    애니메이션없음없음
    열리는 곳모든 앱, 브라우저, 업로드 양식모든 컴퓨터와 휴대폰, 문서 양식

    PDF 페이지는 얼마나 큰가요?

    이미지와 정확히 같은 크기로, 픽셀 하나가 1포인트이며 흰 테두리가 없습니다. 2400 × 1600 사진은 2400 × 1600포인트 페이지가 됩니다. A4나 Letter 용지에 인쇄하려면 인쇄 창에서 '페이지에 맞춤'을 선택하세요. 파일을 줄이려면 고급 옵션에서 최대 너비를 정하거나 품질을 낮추세요.

    이미지 여러 장을 PDF 하나로 합칠 수 있나요?

    여기서는 안 됩니다. 이미지마다 한 페이지짜리 PDF가 따로 만들어집니다. 합치려면 파일 병합이 되는 PDF 리더나 편집기에서 PDF를 여세요. Chrome에서 이미지를 PDF로 저장하는 방법도 참고하세요.

    질문

    PDF로 만들면 사진 화질이 떨어지나요?

    사진은 따로 바꾸지 않으면 품질 92의 JPEG으로 PDF 안에 저장되므로, 차이는 보통 눈에 띄지 않습니다.

    제 문서가 어딘가에 업로드되나요?

    아니요. PDF는 브라우저에서, 사용자의 기기에서 만들어지므로 신분증, 영수증 같은 개인 문서에도 안심하고 쓸 수 있습니다.

    PNG로 PDF를 만들 수 있나요?

    네, PNG를 PDF로를 보세요. 거기서는 투명도가 유지됩니다.
