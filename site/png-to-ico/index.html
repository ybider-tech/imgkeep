    Short answer

    Drop a PNG (or JPG) above, keep ICO selected and download one .ico file that holds the image at 16, 32 and 48 pixels, plus 256 pixels when your image is at least that big. Each size is stored as a PNG inside, so transparency is kept. Images that aren't square are centred on a transparent square. Nothing is uploaded.

    Updated 17 October 2026

    What size should my image be?

    Square and at least 256 × 256 pixels gives the sharpest result, and adds the 256 px size used by Windows for large icons. Smaller images still work: they get the 16, 32 and 48 px sizes.

    Is this the right file for a website favicon?

    Yes. Put it at the root of your site as favicon.ico, and browsers find it on their own. Current browsers also accept a PNG favicon through a <link rel="icon"> tag, but the .ico with several sizes is the most widely recognised.

    Will it work as a Windows icon?

    Yes. Each size inside is stored as a PNG, which Windows reads in icon files, so desktop shortcuts get a sharp icon with a transparent background.

    What about JPG to ICO?

    It works the same way: drop a JPG instead. JPG has no transparency, so the icon keeps the JPG's background.

    Questions

    Why is my icon blurry at 16 px?

    16 pixels is tiny, so detail disappears. Simple shapes and strong contrast work best; very detailed images become a blur at that size.

    Can I choose the sizes?

    Not yet. Every .ico holds 16, 32 and 48 px, plus 256 px when the image is at least 256 px.

    Does it keep transparency?

    Yes. Each size is stored as a PNG inside the .ico, transparency included.
