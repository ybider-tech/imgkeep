    How local conversion works

    Your images are converted by this page, on your device, with the same code as the Imgkeep extension. Nothing is uploaded. The site counts page views, and which formats were converted with how many files (for example "webp → jpg, 3 files"); it never sends image contents, file names or file sizes.

    • Load this page, then turn off your Wi-Fi: converting still works, for every format except AVIF, whose encoder loads the first time you choose it.
    • Open your browser's developer tools, choose the Network tab and convert a file: no request carries your image.
    • The code is public: site/convert on GitHub, with a test that checks converting makes no network request and works offline.

    Updated 25 November 2026

    Why convert AVIF to GIF?

    AVIF animations are tiny and look good, but outside browsers almost nothing plays them: chat apps, presentation software and many social sites expect GIF. Converting gives you a file that plays everywhere, at the cost of a bigger file and fewer colours.

    How do I keep the GIF small?

    Set a Maximum width in Advanced options: halving the width makes the GIF roughly four times smaller. Short loops with few colours stay smallest. Very long or large animations stop at 600 frames or about 150 million pixels in total.

    What about a still AVIF?

    It becomes a one-frame GIF. For still images PNG or JPG are better: see AVIF to PNG or AVIF to JPG.

    Questions

    Does the GIF keep the AVIF's timing?

    Yes. Each frame keeps its own delay, so the animation plays at the same speed.

    Why does the GIF look grainier?

    GIF can show only 256 colours per frame, while AVIF has millions. Gradients and photos show it most.

    Does it work in Safari?

    Safari makes a still GIF of the first frame. Use Chrome, Edge or Firefox to keep the animation.
