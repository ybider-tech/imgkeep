Imgkeep vs Save webP as PNG or JPEG

Коротка відповідь

Обидва безкоштовні й з відкритим кодом. Save webP as PNG or JPEG — відоме доповнення для Firefox, що конвертує будь-яке зображення в PNG або JPEG з кнопками просто над ним. Imgkeep працює в Chrome, Edge і Firefox, зберігає більше форматів, робить анімовані GIF на вашому комп'ютері й не просить доступу до сайтів наперед.

Кому що обрати?

  • Save webP as PNG or JPEG — якщо ви користуєтеся Firefox і хочете PNG або JPEG з кнопками просто над зображенням, а також його прийом із повторним запитом зображення, щоб сайт віддав JPEG або PNG.
  • Imgkeep — якщо ви користуєтеся також Chrome чи Edge, вам потрібні GIF, PDF або WebP, ви хочете конвертувати анімацію на своєму комп'ютері або зберігаєте фото із сайтів, де правий клік заблоковано.

Що добре вміє Save webP as PNG or JPEG

Відоме доповнення від jscher2000 з відкритим кодом за ліцензією MPL 2.0 (код на GitHub). Його сторінка описує:

  • Будь-яке зображення, зокрема WebP і AVIF, у PNG або JPEG, з вибором якості JPEG.
  • Кнопки форматів над зображенням, а Shift+клік чи Ctrl+клік одразу зберігає PNG або JPEG.
  • Копіювання як PNG, після того як ви дозволите доступ до буфера обміну.
  • Теки за датою чи сайтом усередині «Завантажень».

Save webP as PNG or JPEG (Converter) jscher2000 · Firefox

Open source under MPL 2.0, it converts any image, WebP and AVIF included, to PNG or JPEG, with format and quality buttons over the image you right-clicked.

  • Formats saved: PNG, JPEG (quality choice) (Firefox Add-ons listing)
  • Keeps animation: Not in the add-on: a button sends animated WebP to ezgif.com to make a GIF (Firefox Add-ons listing)

  • Copy as PNG: Yes (optional clipboard permission) (Firefox Add-ons listing)
  • Colour palette: Not stated
  • Saves where right-click is blocked: Not stated
  • Choose folder / file names: Yes: Date or site subfolders inside Downloads (Firefox Add-ons listing)
  • Converts locally (no uploads): Not stated
  • Open source: Yes, MPL 2.0 (Firefox Add-ons listing, Source code on GitHub)
  • Site access: All sites (Firefox Add-ons listing)
  • Permissions requested: all sites, downloads, menus, storage, webRequest, webRequestBlocking; optional clipboardWrite, notifications (Firefox Add-ons listing)
