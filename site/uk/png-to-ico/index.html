Конвертер PNG на ICO

Зробіть favicon або іконку для Windows без завантаження файлів: один .ico з усіма поширеними розмірами.

01 Оберіть вихідний формат

Обраний формат: PNG

PNG зберігає прозорість.

Залиште порожнім, щоб зберегти оригінальний розмір. Менші зображення ніколи не збільшуються.

Введіть ціле число пікселів, наприклад 1600.

    Як працює локальна конвертація

    Ваші зображення конвертує ця сторінка, на вашому пристрої, тим самим кодом, що й розширення Imgkeep. Нічого не надсилається на сервер. Сайт рахує перегляди сторінок, а також які формати конвертували та скільки файлів (наприклад, «webp → jpg, 3 файли»); вміст зображень, імена та розміри файлів не надсилаються ніколи.

    • Завантажте цю сторінку, а потім вимкніть Wi-Fi: конвертація все одно працюватиме для всіх форматів, окрім AVIF, кодувальник якого завантажується, коли ви вперше обираєте цей формат.
    • Відкрийте інструменти розробника у браузері, перейдіть на вкладку Network і конвертуйте файл: жоден запит не містить вашого зображення.
    • Код відкритий: site/convert на GitHub, разом із тестом, який перевіряє, що конвертація не робить мережевих запитів і працює офлайн.

    Короткі посібники за форматами

    WebP у JPG

    Потрібен JPG для форми завантаження чи роботи з фото? Оберіть JPG, додайте зображення WebP і завантажте результат. Прозорі ділянки отримають колір фону; обирайте PNG, якщо прозорість треба зберегти.

    Читати посібник «WebP у JPG» →

    WebP у PNG

    PNG підходить для знімків екрана, графіки та зображень, яким потрібна прозорість. Конвертуйте WebP у PNG, коли цього потребує наступна програма. Зміна формату не поверне деталі, які оригінал уже втратив.

    Читати посібник «WebP у PNG» →

    AVIF у JPG

    Маєте зображення AVIF, яке інша програма не відкриває? Конвертуйте його в JPG просто у браузері й завантажте результат. Для графіки з прозорістю обирайте PNG, щоб тло лишилося прозорим.

    Читати посібник «AVIF у JPG» →

    Коротка відповідь

    Перетягніть PNG (або JPG) вище, залиште вибраним ICO — і завантажте один файл .ico, який містить зображення розміром 16, 32 і 48 пікселів, а також 256 пікселів, якщо ваше зображення принаймні таке велике. Кожен розмір зберігається всередині як PNG, тож прозорість лишається. Неквадратні зображення розміщуються по центру прозорого квадрата. Нічого не завантажується на сервер.

    Оновлено 17 жовтня 2026

    Якого розміру має бути моє зображення?

    Найчіткіший результат дає квадратне зображення щонайменше 256 × 256 пікселів — тоді додається й розмір 256 px, який Windows використовує для великих іконок. Менші зображення теж працюють: для них будуть розміри 16, 32 і 48 px.

    Чи підходить цей файл для favicon на сайті?

    Так. Покладіть його в корінь сайту як favicon.ico — і браузери знайдуть його самі. Сучасні браузери також приймають favicon у форматі PNG через тег <link rel="icon">, але .ico з кількома розмірами розпізнається найширше.

    Чи працюватиме він як іконка Windows?

    Так. Кожен розмір усередині зберігається як PNG, а Windows читає такі іконки, тож ярлики на робочому столі отримають чітку іконку з прозорим фоном.

    А як щодо JPG на ICO?

    Так само: просто перетягніть JPG. JPG не має прозорості, тож іконка збереже фон з JPG.

    Питання

    Чому моя іконка розмита на 16 px?

    16 пікселів — це дуже мало, тому деталі зникають. Найкраще працюють прості форми й сильний контраст; дуже деталізовані зображення на такому розмірі перетворюються на пляму.

    Чи можна вибрати розміри?

    Поки ні. Кожен .ico містить 16, 32 і 48 px, а також 256 px, якщо зображення має щонайменше 256 px.

    Чи зберігається прозорість?

    Так. Кожен розмір зберігається всередині .ico як PNG, разом із прозорістю.

    Зберігайте зображення просто з вебу.

    Користуйтеся Imgkeep для Chrome чи Edge, щоб обирати формат одразу під час правого кліку на зображенні: конвертувати файл потім не доведеться.
