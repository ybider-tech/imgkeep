A safe alternative to Save image as Type

For years, "Save image as Type" was the extension people installed to save images from Chrome as JPG or PNG. In March 2026 Google removed it from the Chrome Web Store. Here's what happened, how to check that whatever you install next is safe, and what we made instead.

What happened

  • Save image as Type (ID gabfmnliflodkdafenbcpjdlppllnemd) had over a million users.
  • In late 2025 it changed owner. After that, it fetched a list of shopping sites from a server and inserted affiliate links on them, so commissions on people's purchases went to someone else.
  • Google removed it from the Chrome Web Store in March 2026 (9to5Google).

Users had no way to notice: it kept saving images exactly as before. That's the lesson. An extension can be fine for years, then change after it's sold, and the update arrives automatically.

If you still have it

  1. Type chrome://extensions in the address bar.
  2. If Save image as Type is listed, click Details and compare the ID with the one above, then click Remove. Chrome usually disables extensions removed for malware, but check anyway.

Several extensions in the store today have similar names. They're separate listings, not the one that was removed. Judge each one on its own, with the checklist below.

How to check an image extension is safe

  1. Permissions. Chrome shows them in the "Add extension?" box. "Read and change all your data on all websites" means it can see every page you visit. Saving the image you right-clicked doesn't need that. Asking later for one site, when that site blocks images, is much narrower.
  2. Data. On the store listing, scroll to Privacy. It lists the data the developer says it handles. If an image saver declares "website content", "user activity" or personal information, ask why.
  3. Owner. Check the developer under Details. Be wary if it changed recently, or if an update suddenly asks for new permissions (Chrome turns the extension off until you accept them).
  4. Source. Is the code public, so others can check what it does?
  5. Money. Someone pays for the work. Look for a clear answer: free, a paid plan, or something you can't see.
  6. Reviews. Sort by newest. Watch for redirects, unexpected ads, a surprise paywall, or a run of short, identical five-star reviews.
