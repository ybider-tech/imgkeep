מי צריך לבחור במה?

  • Save webP as PNG or JPEG אם אתם ב-Firefox ורוצים PNG או JPEG עם כפתורים מעל התמונה, וגם את הטריק שלו לבקש את התמונה מחדש כדי שהאתר ישלח JPEG או PNG.
  • Imgkeep אם אתם משתמשים גם ב-Chrome או ב-Edge, צריכים GIF,‏ PDF או WebP, רוצים להמיר אנימציות במחשב שלכם, או שומרים תמונות מאתרים שחוסמים לחיצה ימנית.

במה Save webP as PNG or JPEG טוב

תוסף ותיק של jscher2000, בקוד פתוח ברישיון MPL 2.0 (הקוד ב-GitHub). הדף שלו מתאר:

  • כל תמונה, כולל WebP ו-AVIF, ל-PNG או JPEG, עם בחירת איכות JPEG.
  • כפתורי פורמט מעל התמונה, ו-Shift+לחיצה או Ctrl+לחיצה לשמירה מיידית כ-PNG או JPEG.
  • העתקה כ-PNG, אחרי שמאשרים גישה ללוח.
  • תיקיות לפי תאריך או אתר בתוך ההורדות.

Imgkeep Imgkeep (us) · Chrome, Edge, Firefox

We make Imgkeep, so weigh this row accordingly. It saves the one image you right-click, in nine formats, copies it as PNG, takes its colour palette and can find photos that sites hide from the right-click. Alt+S saves the image under the pointer. It doesn't capture pages, and saving every image on a page at once is coming soon.

  • Formats saved: PNG, JPG, WebP, GIF, PDF; AVIF, ICO, BMP or the original in More options (Chrome Web Store listing)
  • Keeps animation: Yes: GIFs saved unchanged; animated WebP, AVIF and APNG become an animated GIF (Chrome Web Store listing)
  • Bulk save: Coming soon (Imgkeep's own plan; no public page yet.)
  • Copy as PNG: Yes (Chrome Web Store listing)
  • Colour palette: Yes (Chrome Web Store listing)
  • Saves where right-click is blocked: Yes: “Find image here” (off until you turn it on) (Chrome Web Store listing)
  • Choose folder / file names: Yes: Your folder, Downloads, or ask each time; subfolders and file names (Chrome Web Store listing)
  • Converts locally (no uploads): Yes (Chrome Web Store listing)
  • Open source: Yes, MIT (Source code on GitHub)
  • Site access: When asked (manifest.json on GitHub)
  • Permissions requested: contextMenus, downloads, storage, offscreen; optional activeTab, scripting, declarativeNetRequestWithHostAccess (manifest.json on GitHub)
  • No page screenshots (Chrome Web Store listing)
  • Keyboard shortcut: Alt+S (Option+S on a Mac, Alt+Shift+S in Firefox) saves the image under the pointer, and the toolbar button picks from the images on screen (Chrome and Firefox, from 0.15) (manifest.json on GitHub)
  • Stores: Chrome 0.15.0, updated 23 November 2026; Edge 0.12.1, updated 14 November 2026; Firefox 0.15.1, updated 24 November 2026

Save webP as PNG or JPEG (Converter) jscher2000 · Firefox

Open source under MPL 2.0, it converts any image, WebP and AVIF included, to PNG or JPEG, with format and quality buttons over the image you right-clicked.

  • Formats saved: PNG, JPEG (quality choice) (Firefox Add-ons listing)
  • Keeps animation: Not in the add-on: a button sends animated WebP to ezgif.com to make a GIF (Firefox Add-ons listing)
  • Bulk save: Not stated
  • Copy as PNG: Yes (optional clipboard permission) (Firefox Add-ons listing)
  • Colour palette: Not stated
  • Saves where right-click is blocked: Not stated
  • Choose folder / file names: Yes: Date or site subfolders inside Downloads (Firefox Add-ons listing)
  • Converts locally (no uploads): Not stated
  • Open source: Yes, MPL 2.0 (Firefox Add-ons listing, Source code on GitHub)
  • Site access: All sites (Firefox Add-ons listing)
  • Permissions requested: all sites, downloads, menus, storage, webRequest, webRequestBlocking; optional clipboardWrite, notifications (Firefox Add-ons listing)
  • Converts any image, including AVIF, to PNG or JPEG (Firefox Add-ons listing)
  • Shift+click saves PNG, Ctrl+click saves JPEG (Firefox Add-ons listing)
  • Re-requests an image as Internet Explorer 11 to get a JPEG or PNG (Firefox Add-ons listing)
  • Stores: Firefox 1.5.5, updated 30 January 2026
