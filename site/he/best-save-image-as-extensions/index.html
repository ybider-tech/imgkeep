לא משנה במה תבחרו, כדאי להקדיש כמה דקות לבדיקה: כלי לשמירת תמונות רואה את העמודים שבהם לוחצים לחיצה ימנית, ותוסף יכול להשתנות אחרי שנמכר.

  1. הרשאות. "קריאה ושינוי של כל הנתונים שלך בכל האתרים" אומר שהוא יכול לראות כל עמוד שאתם פותחים. בשביל לשמור את התמונה שעליה לחצתם אין בזה צורך.
  2. נתונים. קראו את קטע הפרטיות בדף החנות: מה לדבריו הוא אוסף?
  3. בעלים ועדכונים. בדקו מי מפרסם אותו, והיזהרו אם עדכון מבקש פתאום הרשאות חדשות.
  4. קוד. קוד ציבורי מאפשר לאחרים לבדוק מה הוא עושה.

הרשימה המלאה, ומה קרה ל-Save image as Type המקורי, נמצאות בחלופה בטוחה ל-Save image as Type.

שאלות

איזה תוסף Save Image As הכי טוב?

זה תלוי במה שאתם צריכים. כדי לשמור עמודים שלמים של תמונות, בחרו תוסף עם שמירה המונית. כדי לשמור את התמונה שעליה לחצתם בפורמט הדרוש, בלי העלאות, כל אחד מהתוספים לתמונה בודדת יתאים; השוו פורמטים, הרשאות והאם הקוד ציבורי.

האם התוספים האלה בטוחים?

אנחנו לא שופטים בשבילכם. הטבלה מציגה את ההרשאות שכל אחד מבקש והאם הקוד שלו ציבורי, לפי הדף או החבילה שלו. בדקו גם את קטע הפרטיות בכל דף, וראו איך לבדוק שתוסף תמונות בטוח.

למה בתא כתוב לא צוין?
