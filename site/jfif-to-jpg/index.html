    How local conversion works

    Your images are converted by this page, on your device, with the same code as the Imgkeep extension. Nothing is uploaded. The site counts page views, and which formats were converted with how many files (for example "webp → jpg, 3 files"); it never sends image contents, file names or file sizes.

    • Load this page, then turn off your Wi-Fi: converting still works, for every format except AVIF, whose encoder loads the first time you choose it.
    • Open your browser's developer tools, choose the Network tab and convert a file: no request carries your image.
    • The code is public: site/convert on GitHub, with a test that checks converting makes no network request and works offline.

    Short answer

    Drop your .jfif files above, keep JPG selected and download standard .jpg files. A JFIF file is already a JPEG with a different ending, so apps that reject .jfif accept the result. The conversion runs in your browser, so nothing is uploaded and there's no sign-up. Works in current Chrome, Edge, Firefox and Safari.

    Updated 25 November 2026

    Can't I just rename .jfif to .jpg?

    Yes, for one or two files that's the quickest fix, and it loses nothing: the picture inside is already a JPEG. This page helps when you have many files, when you can't see file endings, or when you also want to resize or shrink them. It saves a fresh JPG at the quality you choose.

    Why do I get JFIF files?

    On some Windows computers, a registry setting tells browsers to name downloaded JPEGs with the .jfif ending. See why Chrome saves images as JFIF for the permanent fix.

    Can I stop getting JFIF files?

    Yes. With the Imgkeep extension, right-click the image on the web page and choose Imgkeep › JPG. It always saves a .jpg file, whatever the Windows setting says.

    Questions

    Is JFIF the same as JPG?

    Yes. JFIF is one of the standard ways JPEG images are stored, so a .jfif file is a JPEG with a different ending.

    Does converting lower the quality?

    Slightly, because the image is saved again as a JPG, at quality 92 unless you change it. Renaming the file instead loses nothing.

    Can I convert JFIF to PNG?

    Yes: see JFIF to PNG. PNG files are larger but keep every pixel.
