Comment nous les avons choisies

Le 24 novembre 2026, nous avons cherché « save image as », « save image as type » et « webp to png » sur le Chrome Web Store, Edge Add-ons et Firefox Add-ons, et retenu les extensions les plus visibles dont le rôle principal est d'enregistrer une image dans un autre format, sans les téléchargeurs en masse ni la recherche d'image inversée. Imgkeep est la nôtre. Nous n'indiquons que ce que chaque éditeur déclare : un tiret ne veut pas dire qu'une extension ne sait pas le faire, seulement que son éditeur ne le dit pas.

Comment choisir une extension sûre

Quelle que soit celle que vous choisissez, quelques minutes de vérification en valent la peine : un outil d'enregistrement d'images voit les pages où vous faites un clic droit, et une extension peut changer après avoir été vendue.

  1. Autorisations. « Lire et modifier toutes vos données sur tous les sites Web » signifie qu'elle peut voir chaque page que vous visitez. Enregistrer l'image sur laquelle vous avez fait un clic droit n'en a pas besoin.
  2. Données. Lisez la section Confidentialité de la fiche : que dit-elle collecter ?
  3. Propriétaire et mises à jour. Vérifiez qui la publie, et méfiez-vous si une mise à jour demande soudain de nouvelles autorisations.
  4. Code source. Un code public permet à d'autres de vérifier ce qu'elle fait.

La liste complète, et ce qui est arrivé au Save image as Type d'origine, se trouvent dans une alternative sûre à Save image as Type.

Questions

Quelle est la meilleure extension Save Image As ?

Cela dépend de votre besoin. Pour enregistrer des pages entières d'images, prenez-en une avec enregistrement en masse. Pour enregistrer l'image sur laquelle vous avez fait un clic droit dans le format voulu, sans envoi, n'importe laquelle des extensions à image unique convient ; comparez les formats, les autorisations et l'ouverture du code.

Ces extensions sont-elles sûres ?

Nous ne jugeons pas à votre place. Le tableau indique les autorisations demandées par chacune et si son code est public, d'après sa propre fiche ou son paquet. Vérifiez aussi la section confidentialité de chaque fiche, et voyez comment vérifier qu'une extension d'images est sûre.

Pourquoi une case indique-t-elle Non précisé ?

Nous n'indiquons que ce que dit chaque éditeur sur sa fiche, son site, son paquet ou son code. Non précisé veut dire que l'éditeur ne dit rien à ce sujet, pas que l'extension ne sait pas le faire.
