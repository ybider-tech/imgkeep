    Comment fonctionne la conversion locale

    Vos images sont converties par cette page, sur votre appareil, avec le même code que l'extension Imgkeep. Rien n'est envoyé. Le site compte les vues de page, ainsi que les formats convertis et le nombre de fichiers concernés (par exemple « webp → jpg, 3 fichiers ») ; il n'envoie jamais le contenu des images, les noms ni les tailles de fichiers.

    • Chargez cette page, puis coupez votre Wi-Fi : la conversion fonctionne toujours, pour tous les formats sauf AVIF, dont l'encodeur se charge la première fois que vous le choisissez.
    • Ouvrez les outils de développement de votre navigateur, allez dans l'onglet Réseau et convertissez un fichier : aucune requête ne transporte votre image.
    • Le code est public : site/convert sur GitHub, avec un test qui vérifie que la conversion n'effectue aucune requête réseau et fonctionne hors ligne.

    Déposez vos fichiers .jfif ci-dessus, laissez PNG sélectionné et téléchargez les PNG. Tout se passe dans votre navigateur, donc rien n'est téléversé.     Mis à jour le 25 novembre 2026

    Quand le PNG est-il le bon choix ?

    Quand une appli ou un service d'impression demande du PNG, ou quand vous retoucherez l'image plusieurs fois : chaque enregistrement en JPG recompresse, alors que le PNG garde ce que vous voyez. Pour envoyer ou partager une photo, le JPG est plus léger : voyez JFIF en JPG.

    Le PNG aura-t-il un fond transparent ?

    Non. Un .jfif (comme tout JPEG) n'a pas de transparence : le PNG garde donc le même fond. Supprimer un fond demande un éditeur d'images.

    Pourquoi ai-je des fichiers .jfif ?

    Un réglage de Windows peut amener les navigateurs à nommer les JPEG téléchargés en .jfif. Pourquoi Chrome enregistre les images en JFIF explique la correction, à faire une seule fois.

    Questions

    La conversion de JFIF en PNG est-elle sans perte ?

    La conversion, oui : le PNG contient exactement les pixels du JFIF. Elle ne peut pas annuler la compression JPEG que l'image avait déjà.

    Pourquoi le PNG est-il si lourd ?

    Le PNG garde chaque pixel sans rien supprimer à la compression : les photos pèsent donc plusieurs fois plus que le JPEG. Définissez une largeur maximale pour l'alléger.

    Puis-je convertir beaucoup de fichiers .jfif à la fois ?

    Oui, jusqu'à 20 à la fois, de 50 Mo maximum chacun.
