    Comment fonctionne la conversion locale

    Vos images sont converties par cette page, sur votre appareil, avec le même code que l'extension Imgkeep. Rien n'est envoyé. Le site compte les vues de page, ainsi que les formats convertis et le nombre de fichiers concernés (par exemple « webp → jpg, 3 fichiers ») ; il n'envoie jamais le contenu des images, les noms ni les tailles de fichiers.

    • Chargez cette page, puis coupez votre Wi-Fi : la conversion fonctionne toujours, pour tous les formats sauf AVIF, dont l'encodeur se charge la première fois que vous le choisissez.
    • Ouvrez les outils de développement de votre navigateur, allez dans l'onglet Réseau et convertissez un fichier : aucune requête ne transporte votre image.
    • Le code est public : site/convert sur GitHub, avec un test qui vérifie que la conversion n'effectue aucune requête réseau et fonctionne hors ligne.

    Réponse courte

    Déposez vos fichiers .jfif ci-dessus, laissez JPG sélectionné et téléchargez des fichiers .jpg standard. Un fichier JFIF est déjà un JPEG avec une autre extension : les applis qui refusent le .jfif acceptent donc le résultat. La conversion se fait dans votre navigateur, donc rien n'est téléversé et aucune inscription n'est nécessaire. Fonctionne dans les versions récentes de Chrome, Edge, Firefox et Safari.

    Mis à jour le 25 novembre 2026

    Ne puis-je pas simplement renommer le .jfif en .jpg ?

    Si : pour un ou deux fichiers, c'est le plus rapide et rien n'est perdu, l'image à l'intérieur est déjà un JPEG. Cette page aide quand vous avez beaucoup de fichiers, quand les extensions sont masquées, ou quand vous voulez aussi les redimensionner ou les alléger. Elle enregistre un nouveau JPG à la qualité de votre choix.

    Pourquoi est-ce que j'obtiens des fichiers JFIF ?

    Sur certains ordinateurs Windows, un réglage du registre fait enregistrer aux navigateurs les JPEG téléchargés avec l'extension .jfif. Voyez pourquoi Chrome enregistre les images en JFIF pour la solution définitive.

    Puis-je ne plus obtenir de fichiers JFIF ?

    Oui. Avec l'extension Imgkeep, faites un clic droit sur l'image dans la page web et choisissez Imgkeep › JPG. Elle enregistre toujours un fichier .jpg, quel que soit le réglage de Windows.

    Questions

    Le JFIF, est-ce la même chose que le JPG ?

    Oui. Le JFIF est l'une des façons standard d'enregistrer les images JPEG : un fichier .jfif est donc un JPEG avec une autre extension.

    La conversion réduit-elle la qualité ?

    Légèrement, car l'image est réenregistrée en JPG, en qualité 92 sauf si vous la modifiez. Renommer le fichier, en revanche, ne fait rien perdre.

    Puis-je convertir un JFIF en PNG ?

    Oui : voyez JFIF en PNG. Les fichiers PNG sont plus lourds mais gardent chaque pixel.
