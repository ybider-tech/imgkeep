Questions

Imgkeep est-il gratuit ?
Oui. Imgkeep est gratuit et open source (MIT), sans compte, sans publicité et sans limite. Toutes les fonctionnalités disponibles aujourd'hui resteront gratuites.
Dans quels navigateurs Imgkeep fonctionne-t-il ?
Google Chrome (sur Windows, macOS, Linux et ChromeOS) et Microsoft Edge (sur Windows, macOS et Linux). La version Firefox est en cours d'examen chez Mozilla et sera listée ici une fois approuvée.
Imgkeep est-il identique dans tous les navigateurs ?
Presque. Dans Firefox, les images sont enregistrées dans votre dossier de téléchargements ou à l'endroit que vous choisissez à chaque fois, car Firefox ne peut pas écrire dans un dossier que vous désignez. Et le résumé d'utilisation quotidien anonyme est désactivé dans Firefox, sauf si vous l'autorisez à l'installation.
Puis-je utiliser Imgkeep sur mon téléphone ?
L'extension est faite pour les navigateurs de bureau. Sur téléphone ou tablette, utilisez le convertisseur d'images gratuit sur imgkeep.app : il convertit les images dans le navigateur, sans les envoyer en ligne.
