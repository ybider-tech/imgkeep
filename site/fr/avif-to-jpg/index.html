    Comment fonctionne la conversion locale

    Vos images sont converties par cette page, sur votre appareil, avec le même code que l'extension Imgkeep. Rien n'est envoyé. Le site compte les vues de page, ainsi que les formats convertis et le nombre de fichiers concernés (par exemple « webp → jpg, 3 fichiers ») ; il n'envoie jamais le contenu des images, les noms ni les tailles de fichiers.

    • Chargez cette page, puis coupez votre Wi-Fi : la conversion fonctionne toujours, pour tous les formats sauf AVIF, dont l'encodeur se charge la première fois que vous le choisissez.
    • Ouvrez les outils de développement de votre navigateur, allez dans l'onglet Réseau et convertissez un fichier : aucune requête ne transporte votre image.
    • Le code est public : site/convert sur GitHub, avec un test qui vérifie que la conversion n'effectue aucune requête réseau et fonctionne hors ligne.

    Déposez vos fichiers AVIF ci-dessus, laissez JPG sélectionné et téléchargez un JPG que toutes les applications et tous les formulaires d'envoi ouvrent.     Mis à jour le 17 octobre 2026

    Comment convertir un AVIF sans rien envoyer en ligne ?

    Déposez les fichiers sur cette page. Votre navigateur ouvre l'AVIF et la page écrit un JPG, sur votre appareil : aucun serveur ne voit vos images, et cela fonctionne hors ligne une fois la page chargée.

    Pourquoi mes applications n'ouvrent-elles pas l'AVIF ?

    L'AVIF est plus récent que la plupart des applications et des formulaires d'envoi. Les navigateurs l'affichent, mais beaucoup d'éditeurs, de systèmes anciens et de sites le refusent encore. Voyez comment enregistrer un AVIF en JPG ou en PNG.

    JPG ou PNG pour un AVIF ?

    JPG pour les photos et pour les fichiers les plus légers, qui s'ouvrent partout. PNG quand l'image a un fond transparent à conserver, ou quand vous allez la retoucher : choisissez PNG dans le menu ci-dessus.

    Quels navigateurs peuvent convertir l'AVIF ?

    Tout navigateur capable d'afficher l'AVIF : Chrome et Edge, Firefox, et Safari sur les versions récentes de macOS et d'iOS. Si le vôtre n'ouvre pas le fichier, le convertisseur vous le dit.

    Puis-je éviter le fichier AVIF la prochaine fois ?

    Oui. Avec l'extension Imgkeep, faites un clic droit sur l'image dans la page web et choisissez Imgkeep › JPG : vous n'avez jamais d'AVIF sur les bras.

    Questions

    Pourquoi mon JPG est-il plus gros que l'AVIF ?

    L'AVIF compresse bien mieux que le JPG : la même image prend donc en général plus de place en JPG. Baissez la qualité ou définissez une largeur maximale pour un fichier plus léger.

    Les AVIF animés sont-ils pris en charge ?

    Le JPG ne garde qu'une image. Pour conserver l'animation, choisissez GIF dans le menu ci-dessus (dans Chrome et Edge).

    Puis-je convertir un AVIF en PNG ?

    Oui : choisissez PNG dans le menu ci-dessus. Le PNG conserve la transparence et chaque pixel.
