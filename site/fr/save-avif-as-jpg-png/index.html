Comment enregistrer un AVIF en JPG ou PNG

Réponse courte

L'AVIF est un format d'image récent et plus léger, que Chrome enregistre tel quel mais que beaucoup d'applications ne savent pas encore ouvrir. Pour obtenir un JPG ou un PNG, enregistrez-le avec un convertisseur comme Imgkeep (clic droit › Imgkeep › JPG), ou exportez-le depuis Preview sur un Mac récent, ou depuis Paint avec l'extension gratuite AV1 Video Extension de Microsoft.

Mis à jour le 28 octobre 2026

Qu'est-ce que l'AVIF ?

L'AVIF est un format d'image récent fondé sur le codec vidéo AV1. Son grand avantage, c'est la taille : un AVIF est en général bien plus léger qu'un JPG de qualité équivalente, et souvent plus léger qu'un WebP. Chrome, Edge, Firefox et Safari l'affichent tous.

Pourquoi Chrome a-t-il enregistré un AVIF ?

Quand Chrome demande une image à un site, il indique les formats qu'il sait afficher, et les versions actuelles citent l'AVIF en premier. Beaucoup de sites et de services d'images s'en servent pour envoyer le fichier le plus léger. Enregistrer l'image sous… enregistre alors exactement ce qui est arrivé, sans conversion. Aucun réglage de Chrome ne permet de changer cela. Il se passe la même chose avec le WebP : pourquoi Chrome enregistre les images en WebP.

Pourquoi mes applications n'ouvrent-elles pas les AVIF ?

Les navigateurs ont adopté l'AVIF rapidement, mais beaucoup d'autres logiciels non : anciennes applications photo et éditeurs, certains outils bureautiques, formulaires d'envoi et services d'impression. Sous Windows, Photos et Paint ont besoin de l'extension gratuite AV1 Video Extension de Microsoft (sur le Microsoft Store) pour ouvrir un AVIF. Les versions récentes de macOS ouvrent les AVIF dans Preview ; les plus anciennes, non.

Comment enregistrer un AVIF en JPG ou PNG en une seule étape ?

Une extension peut convertir l'image au moment où vous l'enregistrez : vous n'avez jamais affaire au fichier AVIF. Elle s'exécute dans votre navigateur, alors choisissez-en une digne de confiance (comment vérifier qu'une extension d'images est sûre).

Comment convertir un AVIF sans extension ?

Le plus rapide pour les fichiers que vous avez déjà : notre convertisseur AVIF vers JPG fonctionne dans votre navigateur, sans rien envoyer en ligne. Choisissez-y PNG pour conserver la transparence.

Windows : Paint

  1. Si Paint n'ouvre pas les fichiers AVIF, installez l'extension gratuite AV1 Video Extension depuis le Microsoft Store.
  2. Faites un clic droit sur le fichier .avif enregistré et choisissez Ouvrir avec › Paint.
  3. Fichier › Enregistrer sous, puis Image JPEG ou Image PNG.

Mac : Preview

  1. Ouvrez le fichier .avif dans Preview.
  2. Fichier › Exporter, puis réglez Format sur JPEG ou PNG.

Si Preview ne l'ouvre pas, votre version de macOS est peut-être trop ancienne pour l'AVIF. Utilisez l'une des autres solutions.

Sur n'importe quel ordinateur : copier-coller

Faites un clic droit sur l'image dans Chrome, choisissez Copier l'image, collez-la dans un éditeur d'images et enregistrez-la en JPG ou PNG. Cela fonctionne même si l'éditeur ne sait pas ouvrir les fichiers AVIF, car Chrome a déjà décodé l'image. La transparence peut être perdue. Si Copier l'image n'apparaît pas dans le menu, c'est que quelque chose recouvre l'image : voir que faire quand le clic droit n'enregistre pas une image.

Une capture d'écran

Win+Maj+S sous Windows, Cmd+Maj+4 sur un Mac. Rapide, mais vous obtenez l'image à la taille de l'écran, pas l'originale.

Convertisseurs en ligne

Ils fonctionnent, mais votre image part sur le serveur de quelqu'un d'autre. Sans problème pour des photos publiques ; à réfléchir à deux fois pour des images privées.

Questions

Faut-il garder les fichiers AVIF tels quels ?

Si toutes vos applications les ouvrent, oui : ils sont légers et de bonne qualité. Convertissez quand un logiciel les refuse, ou quand vous envoyez l'image à quelqu'un d'autre.

La conversion d'un AVIF fait-elle perdre en qualité ?

Enregistrer en PNG conserve les pixels exactement tels quels, mais le fichier devient bien plus lourd. Le JPG recompresse, avec une petite perte généralement invisible à qualité élevée. Pour les fichiers WebP, voir comment enregistrer un WebP en JPG ou PNG.
